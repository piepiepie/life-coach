# 交叉分析工作流

## 概述
本工作流指导 AI 自我探索教练对已有的多模型评估结果进行交叉分析，发现不同模型之间的共振、张力和互补关系，形成更深层次的整合洞察。

## 前置条件
- 用户已完成至少 2 个模型的评估
- 最好有 3 个以上模型的评估结果
- 用户画像中已有各模型的评估数据

---

## 第一步：数据准备

### 1.1 加载模型数据
- 从用户画像中提取所有已完成的模型评估结果
- 整理每个模型的核心发现和关键数据点
- 确认各模型的评估时间和版本

### 1.2 建立分析矩阵
创建一个交叉分析矩阵：

| 模型 A \ 模型 B | MBTI | VIA | Strengths | DISC | Holland | AQAL |
|------------------|------|-----|-----------|------|---------|------|
| MBTI | - | | | | | |
| VIA | | - | | | | |
| Strengths | | | - | | | |
| DISC | | | | - | | |
| Holland | | | | | - | |
| AQAL | | | | | | - |

---

## 第二步：逐对交叉分析

### 2.1 两两模型对比
对于每一对已有的模型，进行以下分析：

**共振识别**：
- 两个模型指向同一结论的发现
- 例如：MBTI N 型 + Holland A 型 = 创造力导向
- 例如：VIA 领导力 + DISC 高 D = 领导型行为模式
- 标记为"高置信度特征"

**张力识别**：
- 两个模型给出矛盾信号的地方
- 例如：MBTI I 型 + DISC 高 I = 社交行为的内外张力
- 例如：VIA 谦虚 + DISC 高 D = 自我表达与克制的张力
- 探索这些张力背后的深层含义

**互补识别**：
- 两个模型各自揭示的侧面互补形成了更完整的图景
- 例如：MBTI 揭示认知偏好，DISC 揭示行为表现，两者互补

### 2.2 记录分析结果
在交叉分析矩阵中记录每对模型的分析结果，包括：
- 共振点（3-5 个）
- 张力点（1-3 个）
- 互补发现（1-3 个）

---

## 第三步：整合洞察

### 3.1 多模型收敛
找出 3 个以上模型共同指向的结论：
- 这些是最可靠的自我认知基础
- 标注为"核心特质"
- 形成 2-3 个核心身份描述

### 3.2 多模型矛盾
找出 3 个以上模型之间的复杂矛盾：
- 这些矛盾通常揭示了人格的丰富性和复杂性
- 可能是不同情境下的不同表现
- 可能是发展中的转化过程
- 形成 1-2 个"复杂性洞察"

### 3.3 盲区推断
基于模型覆盖范围，推断可能存在的盲区：
- 所有模型都未覆盖的领域
- 多个模型一致指向的薄弱环节
- 形成 1-2 个"盲区假说"，供后续验证

---

## 第四步：生成交叉分析洞察

### 4.1 核心主题提炼
从交叉分析中提炼 3-5 个核心主题：
- 每个主题需有至少两个模型的交叉验证
- 每个主题需要具体的解释和实例
- 每个主题需要标注置信度

### 4.2 发展建议整合
基于交叉分析，整合发展建议：
- 哪些发展方向获得多模型支持？（优先方向）
- 哪些发展方向需要平衡多模型的张力？（谨慎方向）
- 哪些发展方向可能填补模型盲区？（探索方向）

### 4.3 教练对话提示
生成可用于教练对话的交叉分析问题：
- "你的 MBTI 显示你是直觉型，而 DISC 显示你偏重影响型，这两者结合让你在团队中可能扮演什么独特角色？"
- "你的 VIA 优势中出现了'审慎'和'勇气'，这两个优势在你做重大决定时如何互动？"

---

## 第五步：更新画像

### 5.1 更新 AI 洞察记录
在画像的"AI 洞察记录"的"交叉分析发现"部分，添加：
- 核心共振发现
- 核心张力发现
- 整合洞察

### 5.2 更新发展建议
在画像的"AI 洞察记录"的"发展建议"部分，更新基于交叉分析的综合建议。

### 5.3 标记需要验证的假说
将交叉分析中产生的"盲区假说"标记为待验证，在后续对话中关注。

---

## 注意事项

1. **避免过度解读**：交叉分析是发现关联，不是建立因果。两件事同时出现不一定意味着它们有因果关系
2. **保持谦逊**：交叉分析的结果是假说而非定论，需要在后续对话中验证
3. **关注最有价值的发现**：不是所有交叉点都值得深入分析，优先关注对用户有实际价值的发现
4. **动态更新**：随着新模型数据的加入，交叉分析结果会不断演化，应定期更新
5. **个性化语言**：用用户能理解的语言表达交叉分析结果，避免过度使用专业术语
