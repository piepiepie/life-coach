# VIA 品格优势探索问题

## 使用说明

VIA 包含 24 项品格优势，分为 6 大美德类别。以下是用于对话探索的引导问题，帮助对方发现自己的"标志性优势"——那些最自然、最核心、最让他们感到"这就是我"的优势。

## 一、发现标志性优势的通用问题

先不要直接进入分类，而是用以下几个通用问题打开对话：

1. 你觉得自己身上有什么东西，是别人不一定看得出来、但你自己很清楚是"你的一部分"？
2. 在什么情况下，你觉得自己是最"对"的——就是那种"我天生就该做这个"的感觉？
3. 别人向你求助的时候，通常是因为什么？他们觉得你在哪方面特别靠谱？
4. 你做过什么事情，让你觉得"成本"很大（时间、精力、情感），但你仍然愿意做？为什么？
5. 你小时候最让大人骄傲的是什么？那个品质现在还在吗？

---

## 二、按美德类别探索

### 智慧与知识（好奇心、创造力、判断力、好学、洞察力）

1. 你最近一次对什么事情感到"特别好奇"？你满足好奇心的方式是什么？
2. 你觉得自己有创意吗？你创造过什么——不一定是什么大作品，可能是一个解决方案、一道菜、一个想法？
3. 面对复杂问题的时候，你通常怎么处理？你喜欢深入分析，还是更相信直觉？
4. 你最近学到的最有意思的东西是什么？你是主动学的，还是碰巧遇到的？
5. 有没有人跟你说过"你点醒了我"？你当时说了什么？

**倾听信号**：频繁使用"我很好奇""我有个想法""换个角度看"等表达。

### 勇气（勇敢、坚韧、诚实、热情）

1. 你做过最需要勇气的事情是什么？不一定是什么惊天动地的事，可能是日常中的一个小决定。
2. 你有没有在一件事上坚持了很久，哪怕别人都不看好？是什么让你坚持下来的？
3. 你觉得自己诚实吗？对自己诚实，还是对别人诚实，哪个更难？
4. 有没有什么事情，你一说起来就停不下来？那种让你眼睛发亮、声音变大的事情？

**倾听信号**：对方在描述困难时表现出的是"我扛过来了"而非"我被击垮了"。

### 仁爱（爱与被爱、善良、社交智慧）

1. 你觉得自己是一个会关心别人的人吗？你关心别人的方式是什么样的？
2. 你最近一次为别人做了什么，让你自己也觉得很温暖？
3. 在社交场合中，你觉得自己最擅长什么？是让人放松，还是读懂气氛，还是记住每个人的细节？
4. 你觉得别人喜欢和你在一起的原因是什么？

**倾听信号**：对方在描述人际关系时，关注的不是"我得到了什么"而是"我给予了什么"。

### 正义（团队合作、公平、领导力）

1. 在团队中，你觉得自己最能贡献什么？是组织协调，还是提出方向，还是照顾每个人的感受？
2. 你看到不公平的事情时，第一反应是什么？你会做什么？
3. 你觉得自己是一个好的领导者吗？好的标准是什么？
4. 你有没有在团队中主动承担过什么责任，不是因为别人要求，而是因为你觉得"应该有人做"？

**倾听信号**：对方对公平、分工、责任有自然的敏感度。

### 节制（宽恕、谦逊、审慎、自控）

1. 你容易原谅别人吗？原谅自己呢？哪个更难？
2. 你觉得自己谦虚吗？你更愿意做那个被看见的人，还是那个在幕后推动事情的人？
3. 你做决定的时候，是深思熟虑型，还是快速行动型？你觉得自己够谨慎吗？
4. 你觉得自己自控力怎么样？什么情况下最容易失控？

**倾听信号**：对方在描述自己的成就时是否有"收敛"的倾向，是否自然地提到他人贡献。

### 超越（欣赏美与卓越、感恩、希望、幽默、灵性）

1. 什么东西让你觉得"美"？是自然景观、艺术作品，还是人的某种品质？
2. 你容易感恩吗？你最近一次发自内心感谢某人或某事是什么时候？
3. 你对未来是乐观的还是悲观的？这种态度是怎么形成的？
4. 你觉得自己幽默吗？你用什么方式让人笑？
5. 你有没有一种"比我自己更大的东西"的感觉？可能是信仰、使命感，或者某种连接感？

**倾听信号**：对方是否能自然地表达感动、敬畏、感激等"超越性"情感。

## 三、识别标志性优势的关键信号

在对话中，注意以下信号来判断某项优势是否为"标志性优势"：

- **自然流露**：对方在描述时不需要刻意组织语言，自然而然就说出来了
- **情感卷入**：说到这个优势时，对方有明显的情绪波动（兴奋、温暖、骄傲）
- **渴望使用**：对方表达出"我希望有更多机会展现这一面"
- **不可替代**：对方说"如果我不能做这件事，我会觉得失去了自己的一部分"
- **快速学习**：与这个优势相关的领域，对方学得特别快

---

## 四、整合与反馈

完成探索后，可以这样整合：

> 从我们刚才的对话中，我注意到几件事特别突出：你____（具体优势1），你在____（具体优势2）上特别自然，而且你好像对____（具体优势3）有很强的渴望。这三样东西，你觉得哪一个最像"你"？哪一个让你觉得"如果余生只能保留一个优势，我会选这个"？

此处的"三选一"追问不是为了限制，而是帮助对方感受优先级——标志性优势通常不超过 5 个，但每个人心中都有一个"最核心"的那个。
