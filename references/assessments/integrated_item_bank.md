# 原创整合题库（Integrated Item Bank）

> 本文档是 `self-discovery-coach` 的**自研轻量题库**，把五大自我认知模型（MBTI / VIA / 克利夫顿 / DISC / 霍兰德）的题项**整合于一处、统一计分**，用于：
> 1. **对话中插入**：AI 在聊天挖天赋时，检测到某维度信号，自动路由插入对应轻量题做验证 / 排序（见 `adaptive_routing.md`）；
> 2. **独立整合测评**（模式 11）：用户一次作答，产出"盖洛普式前 N 排序 + 跨模型交叉"画像。
>
> **版权与信效度声明**：本题库全部题项为基于公开心理学理论**原创自研**，仅用于快速定位倾向与排序，**不复制**任何受版权保护的官方完整题库（MBTI / VIA / CliftonStrengths / DISC / 霍兰德官方量表）。正式结论以官方测评为准。题型库结果在 `real_assessment_bridge.md` 中定义为**中等置信**状态（高于对话推断、低于官方真测评）。

## 一、统一作答与计分规范

### 1.1 题项形态
- **二选一（A/B）**：每题给两种典型反应，用户选更贴近自己的；少数题用 **1–5 程度** 或 **多选最像的 2–3 项**。
- 每模型题量经过压缩（MBTI 12 / VIA 10 / 克利夫顿 16 / DISC 8 / 霍兰德 12），单模型 2–4 分钟，全量约 12–18 分钟。克利夫顿 16 题已覆盖 34 才干中绝大多数高频主题。

### 1.2 计分规则（全模型通用）
- 每题所选一侧记 **1 分**，累计到对应维度 / 主题。
- **排序输出**：各模型按得分降序取前 N（N 见各模型）。
- **置信度**：据答题覆盖度与信号强度给 **强 / 中 / 弱**：
  - 强：核心维度得分 2–3 分差且覆盖完整 → 可作高置信倾向
  - 中：有清晰主导但个别维度接近 → 方向可信
  - 弱：仅 1 题覆盖或 A/B 接近 → 标注"待验证，建议补官方测评"
- 任何排序都带缓冲语："这更像你的**主导倾向**，不是定论"。

### 1.3 与既有模块衔接
- 计分后按 `cross_model_mapping.md` 做跨模型交叉（一致性 / 张力点，须走 §十三 反幻觉校验）。
- 排序结果落入 AQAL 四象限（UL 内在天赋 / UR 行为风格 / LL·LR 兴趣与场景），见 `aqal.md`。
- 题型库结果作为 `real_assessment_bridge.md` 的**第三状态**进入交叉分析与职业安放。
- **计分对齐**：本文件是 `self-discovery-coach` 的**统一计分规范**（MBTI 0–3 维分 + 类型 + 置信度 / VIA Top5 / 克利夫顿 Top5 + 四类计数 / DISC 主+次型 / 霍兰德 三位码）。外部 `assessment-models` skill 的 `scoring.md` 与之采用**同一套字段结构**（见其"与 self-discovery-coach 整合题库的计分对齐"段），避免双套计分逻辑漂移；任一处调整须同步另处。

## 二、MBTI 轻量题库（4 维度 × 3 题 = 12 题）

**计分**：每维度 A/B 各计 1 分，得 2–3 分侧为主导，1 分为弱倾向；四字母组合成类型。

**E/I 能量指向**
1. 周末补给方式：A 找人聚聚才有劲 / B 自己待着才回血
2. 一场热闹后：A 觉得被点燃 / B 需要安静缓一缓
3. 想事情时：A 喜欢边聊边理清 / B 习惯先在脑子里想透

**S/N 信息接收**
4. 听介绍更被：A 具体步骤和细节吸引 / B 全局和"以后能怎样"吸引
5. 你更容易记住：A 实际发生的事实 / B 这件事给你的感觉和联想
6. 别人常评价你：A 务实、接地气 / B 脑洞大、想得远

**T/F 决策依据**
7. 劝朋友时：A 帮他理清楚利弊 / B 先接住他的情绪
8. 你更怕被说：A 不讲道理 / B 不近人情
9. 选工作看：A 发展空间和回报逻辑 / B 团队氛围和价值观契合

**J/P 生活态度**
10. 出门前：A 提前列好计划 / B 到了再看情况
11. 面对截止日：A 早就做完了 / B 临近才进入状态
12. 你更享受：A 事情定下来的踏实 / B 保留选择的自由

## 三、VIA 品格优势轻量题库（10 组配对 → Top5）

> 基于 VIA 24 项优势 / 6 美德（智慧、勇气、人道、正义、节制、超越）。每题给两种优势倾向，选更"像你本能"的；可多选最像的 2–3 项。结算 Top5 显著优势。

1. 遇到困难时你更靠：A 好奇心去搞懂它 / B  bravery 硬着头皮上
2. 你更常被人夸：A 点子多、有创意 / B 靠谱、有定力
3. 与人相处你更在意：A 公平、讲规则 / B 善良、顾及感受
4. 你更容易被触动：A 一句有洞察的话 / B 一个温暖的瞬间
5. 闲暇你更可能：A 学点新东西（热爱学习）/ B 回味生活里的美（欣赏卓越）
6. 团队里你常是：A 出主意的那个人 / B 稳住节奏的那个人
7. 你更珍惜自己：A 能看透本质的清醒 / B 心怀希望的乐观
8. 你更自发地：A 帮人善后（责任心）/ B 逗人开心（幽默）
9. 你更认同：A 谦虚、知边界 / B 感恩、记好事
10. 你更常被说：A 有灵性 / 通透 / B 社交智慧高、懂人情

**结算**：10 题累计，各优势得分降序取 Top5；其余列入"次要优势"。

## 四、克利夫顿 才干轻量题库（16 场景 → Top5，覆盖 34 才干）

> 基于 34 才干四分类（执行力 / 影响力 / 关系建立 / 战略思维）。每题给一个本能场景，选"最像你默认反应"的才干；结算 Top5 主导才干。才干是"天生反复出现的模式"，非技能熟练度。
> 本题库 16 题已覆盖 34 才干中绝大多数高频主题（每题括注对应才干，便于核对）；若某才干接近，标注"并列"。

**执行力（Executing）**
1. 接个大任务，你默认：A 立刻拆步骤开干（成就/行动） / B 先排优先级保质量（纪律/审慎）
2. 事情卡住时你：A 直接上手逐个排难（统筹/修复） / B 找对的人补位（统筹）
3. 你更被信任做：A 要准时交付的关键节点（责任/专注） / B 不能出错的敏感环节（审慎/公平）
4. 长期做事你：A 一旦认准就稳稳推进到底（成就/纪律） / B 凡事按原则和价值观做判断（信仰/责任）

**影响力（Influencing）**
5. 一个有争议的想法，你：A 主动站出来讲清楚（统率/沟通） / B 等时机成熟再推（主动/自我）
6. 表达观点时你：A 享受被听见、被讨论 / B 追求把别人也点燃（演说/唤醒）
7. 比赛中你：A 被"要赢"点燃（竞争） / B 想让自己/团队做到最好（最大化）
8. 陌生人场子里你：A 很快和人熟络、记小事（交往/WOO） / B 享受成为关注中心（自我/意义）

**关系建立（Relationship Building）**
9. 新环境里你：A 很快和人熟络、记小事（交往/个别） / B 先观察谁需要被照顾（体谅/同理心）
10. 朋友低谷时你：A 陪着、不急着给建议 / B 帮他看到自己被低估的亮点（伯乐/积极）
11. 你更享受：A 和一两个人深交（亲切/关联） / B 让气氛轻松、大家都有被包括（和谐/包容）
12. 团队里有矛盾你：A 自然去调和、让大家都能说话 / B 先稳住关系不让局面裂（和谐/关联）

**战略思维（Strategic Thinking）**
13. 看到复杂局面你：A 自动找底层规律 / B 联想到多种可能（分析/战略）
14. 你更享受：A 钻进一个主题深读（输入/学习） / B 一个人把问题想透（思维/理念）
15. 规划时你：A 回头看历史经验避坑（回顾/前瞻） / B 连点成线看到趋势（连系）
16. 你常被人说：A 看问题比别人深 / B 总能想到"下一步怎么走"（战略/理念）

**结算**：每类累计，跨四类取 Top5 才干；标注四类计数（战略思维/影响力/关系建立/执行力）。若某类明显偏重，提示"你更偏 X 类才干"，便于职业安放时匹配团队角色。

## 五、DISC 轻量题库（4 型 × 2 题 = 8 题）

> 四型：D 支配（结果导向）/ I 影响（人际导向）/ S 稳健（稳定导向）/ C 谨慎（准确导向）。每题选更贴近的反应；结算主型 + 次型。

1. 推进一件事你更：A 直接拿结果、不怕冲（D） / B 先照顾大家情绪（S）
2. 遇到阻力你：A 正面刚、调资源破局 / B 绕开、找更稳的路径
3. 开会你更可能：A 活跃气氛、带动讨论（I） / B 默默把数据核对准（C）
4. 你更被说：A 有人格魅力、能带节奏 / B 细致、出错少
5. 变化来袭你：A 兴奋、觉得有机会（I） / B 先确认会不会乱（C）
6. 你更看重：A 关系顺、团队稳 / B 流程对、不出错
7. 决策时你：A 快、凭直觉抓重点（D） / B 慢、等信息齐（C）
8. 你更享受：A 被人围绕、有互动 / B 按部就班、可预期

**结算**：D/I/S/C 各计累计分，最高为主型、次高为次型；一句话风格如"影响为主、谨慎为辅"。区分本色与角色需要（职场面具 ≠ 天赋本色）。

## 六、霍兰德 RIASEC 轻量题库（6 型 × 2 题 = 12 题）

> 六型：R 现实 / I 研究 / A 艺术 / S 社会 / E 企业 / C 常规。每题选更投入的活动；结算三位兴趣码（首位权重最高）。

**R 现实型**
1. 你更享受：A 动手修/做东西 / B 和人讨论想法
2. 你更擅长：A 用工具或身体解决问题 / B 用语言说服人

**I 研究型**
3. 你更被：A 一个还没答案的问题吸引 / B 一个能展示成果的项目吸引
4. 你更可能：A 查资料自己搞明白 / B 找人合作推进

**A 艺术型**
5. 你更自在：A 自由创作、不守套路 / B 按标准把事做漂亮
6. 你更被夸：A 有审美、有表达力 / B 有条理、靠得住

**S 社会型**
7. 你更满足于：A 帮人解决困难 / B 把系统跑顺
8. 你更倾向：A 一对一深度陪伴 / B 一对多带动氛围（I 交叉）

**E 企业型**
9. 你更想：A 牵头、对结果负责 / B 把专业做精
10. 你更被：A 目标、胜出、影响打动 / B 稳定、把事做对打动

**C 常规型**
11. 你更舒服：A 流程清晰、记录整齐 / B 灵活应变
12. 你更擅长：A 核对、归档、不出错 / B 临场发挥

**结算**：六型计分降序，取前三为兴趣码（如 AES）；首位权重最高，用于职业映射（见 `career_mapping.md`）。

## 七、跨模型交叉输出（一致性 / 张力点）

结算五大模型排序后，按 `cross_model_mapping.md` 做交叉，并**强制走 §十三 反幻觉校验**：
- **一致性信号**（多模型指向同一结论）：如 MBTI N + 克利夫顿 战略/理念 + 霍兰德 I/A → 强"创新探索"倾向。
- **张力点**（模型间矛盾）：如 MBTI E + DISC C → 外向好社交但谨慎慢热；原样保留，不抹平、不投票，交元视角仲裁。
- 每个强信号必须同时给出**支持证据 + 反对证据 + 主动构造反例**，根治一致性幻觉。

### 输出样例（给用户看，非 JSON）
```
【整合画像 · 中等置信】
天赋内核（克利夫顿 Top5）：战略 · 理念 · 学习 · 输入 · 思维
认知底色（MBTI）：ENFP
行为风格（DISC）：影响为主、谨慎为辅
兴趣方向（霍兰德）：A-E-S
显著优势（VIA Top5）：创造力 · 好奇心 · 热爱学习 · 希望 · 善良

一致性：N+战略+理念+I/A → 强"从可能性中造结构"倾向
张力点：E 外显 但 DISC C 谨慎 → 社交中偏观察，非外向主导
下一步：可补官方 CliftonStrengths / VIA 提升置信度
```

### 7.1 题型库结果 → 职业映射衔接示例（治"方向多无聚焦"）

拿到上例排序后，按以下链路把"中等置信的排序"转为"可落地的方向 + 动作"：

1. **取主导信号**：霍兰德首位 A/E + MBTI N + 克利夫顿 战略/理念 + VIA 创造力/好奇心。
2. **命中职业映射**：以上信号 → 查 `career_mapping.md` 命中「A 艺术型 × E 企业型 / 社会创新 / 内容创业」类；霍兰德 A → 命中 `career_database.md`「创意设计 / 自由职业·自媒体」。
3. **读取 Playbook**：若落入 `career_playbook_template.md` 已覆盖方向（如 内容策略 / 自由职业·自媒体 / UX 设计），**直接读取对应 Playbook** 给用户——含 3 个月路径、信息访谈 8 问、作品集方案、验证里程碑。
4. **未覆盖方向**：按 Playbook「标准结构」即时生成精简版，并标注"此份为即时生成，建议进一步验证"。
5. **差距分析**：结合用户现实约束（城市/资本/可投入时间/家庭阶段）做 `career_mapping.md` §九 差距分析，输出能力/时间/资金三类缺口 + 相邻替代方向。

> 这一步把"对话式发现的多种天赋信号"收束成"聚焦的 1–3 个方向 + 可执行动作"，根治原技能"信号多但无聚焦"的短板。

### 7.2 排序后市场数据校验（可选，接 `market_data_protocol`）

- **有联网环境**（具备 WebSearch/WebFetch）：排序产出方向后**自动触发** `market_data_protocol.md` 拉「市场现实卡」，校验方向热度 / 门槛 / 趋势（需求增长·平稳·萎缩）。
- **无联网环境**：跳过本步，并明确告知"未接入市场数据，以下方向仅为画像推断，请自行核实"，**不得编造数字**（见 `market_data_protocol.md` §七 降级处理）。
- **冲突处理**：若市场卡与排序对照冲突（如排序指向某萎缩赛道），AI 主动提示并给相邻方向（见 `career_mapping.md` §九 差距分析 + 相邻替代）。

## 八、使用注意
- 题库为**原创轻量版**，排序用于"聚焦方向"，不等同官方排序。
- 克利夫顿/ VIA 题项压缩后覆盖有限，Top5 仅代表本次作答倾向；若某才干接近，标注"并列"。
- 题型库结果与对话推断、官方真测评三者并列使用：以官方为准，题型库居中，对话推断作探索起点（见 `real_assessment_bridge.md`）。
- 不复制、不宣称等同任何受版权保护的官方测评。
