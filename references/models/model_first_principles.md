# 19 个心理学模型的底层逻辑

> **底层逻辑 = 为什么产生 + 底层假设 + 为什么能帮人解决问题**
>
> 理解一个模型的底层逻辑，比记住它的分类和类型更重要。底层逻辑告诉你：什么时候该用这个模型、什么时候不该用、它和别的模型有什么本质区别。

---

## 1. 心流理论 (Flow State)

### 为什么产生？

Mihaly Csikszentmihalyi 在 1960 年代研究"创造力"时，发现了一个反直觉的现象：艺术家在创作时，即使没有报酬、没有外部奖励，也会废寝忘食地投入。他们不是为了钱，而是因为"做这件事本身"就让人满足。于是 Csikszentmihalyi 开始研究这种"最优体验"状态，提出了心流理论。

**要解决的问题**：为什么人在没有外部奖励的情况下，仍然会投入大量精力做某些事？什么样的体验让人感到真正的满足？

### 底层假设

1. 人的最优体验来自于"行动本身"而非"行动的结果"——内在动机比外在动机更持久
2. 心流发生在"挑战与技能刚好匹配"的区间——太简单会无聊，太难会焦虑
3. 心流状态是天赋正在被使用的信号——你进入心流的事，大概率是你的天赋所在
4. 心流不是"放松"，而是"高度投入"——它不是被动享受，而是主动投入

### 为什么能帮人解决问题？

它帮人识别**天赋信号**。很多人"不知道自己喜欢什么"、"不知道自己擅长什么"——但如果你问他们"什么时候忘了时间"，他们能说出来。心流就是天赋的 GPS，它告诉你"往这里走"。

## 2. MBTI（认知偏好）

### 为什么产生？

二战期间，大量女性首次进入工厂工作。Katharine Briggs 和女儿 Isabel Myers 观察到，很多女性被分配到不适合她们的岗位，导致效率低下、士气低落。她们基于荣格的心理类型理论，开发了 MBTI，目标是：**帮人找到和自己认知偏好匹配的工作**。

**要解决的问题**：为什么同一件事，有的人做起来轻松，有的人做起来痛苦？有没有一种方法，能帮人找到"适合自己思维方式"的工作？

### 底层假设

1. 每个人都有天生的认知偏好（不是能力，是偏好）——就像有人天生左撇子、有人右撇子
2. 偏好没有好坏，但不同偏好适合不同的环境和工作
3. 做符合认知偏好的事，消耗更少能量、产出更好结果
4. 偏好是流动的，不是固定的——你可以在需要时使用非偏好功能，但会消耗更多能量

### 为什么能帮人解决问题？

它帮人理解"为什么我在某些事上消耗特别大"。一个内向的人在需要频繁社交的工作中会很累——不是因为能力不行，而是因为偏好不匹配。MBTI 不是告诉你"你适合做什么"，而是帮你理解"什么方式更适合你"。

## 3. CliftonStrengths（优势识别/盖洛普）

### 为什么产生？

Don Clifton 在二战后的教育研究中发现了一个关键问题：**心理学花了太多时间研究"人哪里出了问题"，而几乎没花时间研究"人哪里做对了"**。他问了一个改变方向的问题："如果我们研究'人最擅长什么'，而不是'人最不擅长什么'，会发生什么？"

盖洛普后来做了一个大规模研究：问全球 1000 万人"你每天有机会做自己最擅长的事吗？"。结果发现，只有 20% 的人回答"是"。而这 20% 的人，在工作投入度、幸福感、绩效上都远超其他人。

**要解决的问题**：为什么大多数人在工作中没有发挥自己的优势？如果我们帮助人们识别并发展优势，而不是修补短板，会怎样？

### 底层假设

1. 天赋是自然反复出现的思维、感受和行为模式——它不是你学会的，而是你"忍不住"会做的
2. 天赋 × 投入 = 优势——光有天赋不够，需要刻意练习和知识投入
3. 修补短板投入产出比极低——从"差"提升到"一般"需要大量精力，从"好"提升到"卓越"反而更高效
4. 最大的成长空间在"你最擅长的事"上，不在"你最不擅长的事"上

### 为什么能帮人解决问题？

它帮人从"我哪里不够好"转向"我哪里与众不同"。很多人不觉得自己有什么天赋——因为他们觉得"做起来轻松"的事不值一提。但盖洛普告诉你：那些你做起来轻松、别人觉得难的事，就是你的天赋。它帮你重新定义"什么是优势"。

## 4. DISC（行为风格）

### 为什么产生？

William Marston 在 1928 年提出 DISC 理论，他观察到**人的行为风格是可观察的、可分类的，而且是可调整的**。他不是要给人贴标签，而是想帮人理解："为什么我和某些人合作特别顺畅，和另一些人特别费劲？"

**要解决的问题**：为什么同样一个任务，不同的人会用完全不同的方式去完成？为什么有些团队合作如鱼得水，有些团队冲突不断？

### 底层假设

1. 行为风格不是性格，而是**可观察的行为倾向**——它比性格更容易改变
2. 每个人都有四种风格，只是比例不同——不是"你是 D"，而是"你的 D 比较高"
3. 不同风格之间没有好坏，但不同风格在不同环境下效果不同
4. 理解自己和他人的风格，可以改善沟通和协作

### 为什么能帮人解决问题？

它帮人理解"为什么我和某些人合不来"——不是因为对方是坏人，而是因为风格不同。一个高 D（直接、果断）的人和一个高 S（稳健、耐心）的人在一起工作，天然的节奏就不同。DISC 让你看到：这不是"对错"问题，是"风格"问题。

## 5. VIA 品格优势

### 为什么产生？

Martin Seligman 和 Christopher Peterson 在 2000 年代初，想回答一个问题：**"积极心理学有没有一个分类体系，能和 DSM（精神疾病诊断手册）对应？"** DSM 是对"人哪里出了问题"的分类，VIA 想做一个对"人哪里做对了"的分类。

他们花了三年时间，研究了全球 3000 年来的哲学、宗教、文化文本，找出了跨文化共通的 24 个品格优势。

**要解决的问题**：有没有一套"人类优势"的分类体系，可以跨文化、跨时代适用？一个人最核心的价值观是什么？

### 底层假设

1. 品格优势是跨文化的——不同文化对"好"的定义不同，但有一些核心优势是共通的
2. 每个人的"标志性优势"（Signature Strengths）是核心价值观的体现
3. 使用标志性优势时，人会感到"这就是真正的我"
4. 每天使用标志性优势的人，幸福感和满足感更高

### 为什么能帮人解决问题？

它帮人识别"什么对我真正重要"。很多人说不清自己的价值观，但 VIA 通过 24 个优势的排序，帮你看到：排在前面的不是你"会"的，而是你"在乎"的。它把抽象的"价值观"变成了可排序、可讨论的具体条目。

## 6. 霍兰德职业兴趣 (Holland)

### 为什么产生？

John Holland 在 1950 年代做职业咨询时发现，**很多人选职业时只看"钱"和"地位"，完全不考虑"我是不是真的喜欢做这个"**。结果就是：做着做着就 burnout 了。他提出：职业选择应该和人的兴趣类型匹配，而不是只看外部条件。

**要解决的问题**：为什么有人做一份高薪工作却痛苦不堪？如何帮人找到"和自己兴趣匹配"的职业方向？

### 底层假设

1. 人的职业兴趣可以分为六种类型，大多数人是一个组合（如 EAS）
2. 工作环境也有"类型"——一个研究型的人在研究型环境中会更满足
3. 兴趣和环境的匹配度越高，工作满意度和稳定性越高
4. 兴趣不是"你擅长什么"，而是"你被什么吸引"——你可能对某件事感兴趣但不擅长，也可能擅长某件事但不感兴趣

### 为什么能帮人解决问题？

它帮人把"我喜欢什么"从模糊的感觉变成可讨论的类型。很多人说"我不知道自己喜欢什么"，但如果你给他们描述六种工作场景，他们能告诉你"这个更像我"、"那个完全不是我"。霍兰德提供了一个讨论"兴趣"的语言。

## 7. 九型人格 (Enneagram)

### 为什么产生？

九型人格的起源可以追溯到古代的神秘传统（苏菲教、基督教沙漠教父等），但现代心理学版本由 Oscar Ichazo 和 Claudio Naranjo 在 1970 年代整合。它和其他人格模型最大的不同是：**它不问"你做什么"，而是问"你为什么这样做"**。

**要解决的问题**：为什么有些人在类似的情况下总是做出同样的"不那么明智"的选择？什么在驱动人的行为——不只是偏好，而是深层动机和恐惧？

### 底层假设

1. 每个人都有一种核心恐惧和核心动机，它们在童年形成，并持续驱动成年后的行为
2. 人格不是"你是谁"，而是"你用来应对世界的策略"——这个策略曾经保护过你，但可能现在不再需要了
3. 每种类型在压力下和放松时，会表现出不同的特征（压力方向和放松方向）
4. 了解自己的类型，不是给自己贴标签，而是看到"我一直在用同一种策略应对世界"

### 为什么能帮人解决问题？

它帮人看到"我为什么总是这样"。当一个人反复遇到同样的困境——比如总是在关系中过度付出（类型 2）、总是害怕失败而不行动（类型 3/6）、总是回避冲突（类型 9）——九型人格告诉他们：这不是你的错，这是你的"策略"，而这个策略是可以被意识到的、可以被调整的。

## 8. 螺旋动力学 (Spiral Dynamics)

### 为什么产生？

Clare W. Graves 在 1950 年代研究心理学学生时发现，**不同的人对"什么是成熟"有完全不同的定义**。他意识到：人的价值观不是在一条线上从"差"到"好"，而是在一个螺旋上从"简单"到"复杂"不断演化。后来 Don Beck 和 Chris Cowan 将他的理论系统化为螺旋动力学。

**要解决的问题**：为什么同样一件事，有人觉得"这是对的"，有人觉得"这是错的"？价值观的差异是怎么来的？人如何从一种价值观演化到另一种？

### 底层假设

1. 价值观不是"好"或"坏"，而是"简单"或"复杂"——每个阶段都是对前一阶段的超越和包含
2. 人的价值观演化不是线性的，而是螺旋上升的——你会不断回到类似的问题，但每次都在更高的层次
3. 一个人可以同时处于多个阶段——在工作中是橙色（成就导向），在家庭中是蓝色（规则导向）
4. 每个阶段都有正面和负面表现——橙色可以有"健康的竞争"和"不健康的贪婪"

### 为什么能帮人解决问题？

它帮人理解"为什么我以前觉得对的，现在觉得不对了"——这不是你变坏了，而是你的价值观在演化。它也帮人理解"为什么我和某些人无法沟通"——不是因为谁对谁错，而是因为你们处于不同的价值阶段，说着不同的语言。

## 9. Ikigai（活着的理由）

### 为什么产生？

Ikigai 来自日本冲绳，这个地区以长寿著称。研究者发现，冲绳老人的一个共同特点是：**他们都有一个"早上起床的理由"**——不是赚钱、不是义务，而是一种"做这件事让我觉得活着有意义"的感觉。

**要解决的问题**：为什么有些人活得久而且快乐？有没有一种方法，能帮人找到"热爱+擅长+被需要+能赚钱"的交集？

### 底层假设

1. 真正让人满足的人生，不是"赚钱"或"热爱"二选一，而是四个维度的交集
2. 四个维度不需要一开始就完美对齐——Ikigai 是逐步逼近的，不是一次性找到的
3. 即使只满足三个维度，人生也可以很充实——但缺失的那个维度会一直提醒你
4. Ikigai 会随着人生阶段变化——30 岁的 Ikigai 和 50 岁的 Ikigai 可能不同

### 为什么能帮人解决问题？

它帮人把"我不知道该做什么"拆解成四个可回答的问题。与其问"我的人生方向是什么"（太宏大），不如问"我热爱什么？我擅长什么？世界需要什么？什么能赚钱？"——然后找交集。它把一个虚无缥缈的问题，变成了四个具体的问题。

## 10. 叙事身份 (Narrative Identity)

### 为什么产生？

Dan McAdams 在 1980 年代研究人格心理学时发现，**传统的人格理论（特质论）只能描述人的"骨架"，但无法描述人的"故事"**。两个人可能有完全相同的人格特质，但他们对自己人生的理解——他们的"叙事身份"——完全不同。一个人把自己的苦难理解为"救赎"，另一个人理解为"污染"。

**要解决的问题**：为什么两个经历相似的人，对自己人生的理解完全不同？"你怎么讲述自己"比"你是什么样的人"更重要，为什么？

### 底层假设

1. 人不是通过"特质"来理解自己的，而是通过"故事"——"我是一个什么样的人"本质上是一个叙事
2. 叙事不是客观的——同一个事实可以有不同的讲述方式，不同的讲述方式产生不同的自我认知
3. 限制性叙事（"我从来都不擅长……"）会限制人的可能性，但它曾经是有用的——它帮你解释和应对过去
4. 重新讲述自己的故事，可以改变自我认知和未来行为

### 为什么能帮人解决问题？

它帮人看到"我一直在讲什么故事"。当你发现你一直在讲"我总是关键时刻掉链子"的故事时，你可以问自己：这是事实，还是我选择讲述的版本？有没有例外？如果我换一个故事讲，会怎样？叙事身份让你从"故事的囚徒"变成"故事的作者"。

## 11. 可能自我 (Possible Selves)

### 为什么产生？

Hazel Markus 和 Paula Nurius 在 1986 年提出，**人的行为不仅受"现在的我"驱动，还受"我希望成为的我"和"我害怕成为的我"驱动**。你选择做某件事，不只是因为它是"对的"，而是因为它在帮你靠近"希望自我"或远离"恐惧自我"。

**要解决的问题**：为什么有些人有强烈的动力，有些人没有？"我想成为什么样的人"这个想法，如何影响现在的行为？

### 底层假设

1. 人的行为是"现在自我"和"可能自我"之间张力的产物
2. 希望自我（你想成为的）提供"拉力"，恐惧自我（你害怕成为的）提供"推力"
3. 如果希望自我和预期自我差距太大，会产生无力感；如果差距适中，会产生动力
4. 可能自我不是固定的——你可以主动创造新的"可能自我"来驱动自己

### 为什么能帮人解决问题？

它帮人把"我不知道自己想要什么"转化为"你羡慕谁？你害怕变成谁？"。通过激活"可能自我"的想象，帮人找到方向感。它也帮人识别：你现在的很多行为，其实是在"逃离恐惧自我"还是"靠近希望自我"？如果是前者，你只是在逃跑，而不是在前进。

## 12. 变革免疫 (Immunity to Change)

### 为什么产生？

Robert Kegan 和 Lisa Lahey 在哈佛大学研究"领导力发展"时发现，**很多高管明明知道需要改变，也真心想改变，但就是改不了**。他们不是不努力，不是不聪明——而是有一个隐藏的"免疫系统"在阻止他们。这个免疫系统本来是保护他们的，但同时也阻止了成长。

**要解决的问题**：为什么聪明人明明知道要改，但就是改不了？那个"改不了"的背后，在保护什么？

### 底层假设

1. 每个人都有一个隐藏的"免疫系统"——一套无意识的假设和承诺，它保护你免于焦虑，但也阻止你改变
2. 你"做"的事情（反向行为）和"不做"的事情，都是在服务一个隐藏的承诺
3. 隐藏的承诺背后，有一个"重大假设"——这个假设你从来没有验证过
4. 改变不是"打破"免疫系统，而是"看到它"，然后决定是否调整

### 为什么能帮人解决问题？

它帮人看到"我改不了不是因为我不够努力，而是因为我在保护自己"。当你发现"我拖延不是因为懒，而是因为'如果我不完美就是失败'这个假设"，你就可以开始问：这个假设是真的吗？有没有验证过？变革免疫把"改不了"从道德问题（"你不够自律"）变成了认知问题（"你有一个假设需要验证"）。

## 13. 乔哈里窗 (Johari Window)

### 为什么产生？

Joseph Luft 和 Harry Ingham 在 1955 年研究"团队沟通"时发现，**团队中最有效的成员，是那些"公开区"最大的人**——他们知道别人怎么看自己，也愿意让别人知道真实的自己。而低效的成员，往往有巨大的盲区或隐藏区。

**要解决的问题**：为什么有些人在团队中如鱼得水，有些人总是被误解？如何帮人减少盲区、扩大公开区？

### 底层假设

1. 人的自我认知有四个区域：公开区、盲区、隐藏区、未知区
2. 盲区是"别人知道但自己不知道"的部分——它只能通过反馈来缩小
3. 隐藏区是"自己知道但别人不知道"的部分——它只能通过分享来缩小
4. 未知区是"自己和别人都不知道"的部分——它只能通过探索来发现
5. 扩大公开区 = 增加信任 + 减少误解

### 为什么能帮人解决问题？

它帮人回答："为什么别人对我的看法和我不一样？"当你发现你的盲区——别人看到但你不知道的——你就能理解为什么有些冲突反复发生。它也帮人看到：你不敢分享的（隐藏区），可能恰恰是别人需要知道的。

## 14. 自我决定理论 (Self-Determination Theory)

### 为什么产生？

Edward Deci 和 Richard Ryan 在 1970 年代做了一个著名的实验：他们发现，**当外部奖励被引入时，人们的内在动机反而下降了**——这就是"过度理由效应"。他们由此开始研究：什么条件会激发内在动机？什么条件会扼杀它？

**要解决的问题**：为什么有些人对工作充满热情，有些人只是在"熬"？什么条件能让人真正投入，而不是被迫做事？

### 底层假设

1. 人类有三种基本心理需求：自主性（Autonomy）、胜任感（Competence）、关系感（Relatedness）
2. 这三种需求是跨文化的、普遍的——就像身体需要营养一样，心理需要这三种"营养"
3. 当三种需求都满足时，内在动机自然产生；当任何一种受挫时，投入度和幸福感下降
4. 外部奖励（钱、地位）在三种需求受挫时，只能短期补偿，长期无效

### 为什么能帮人解决问题？

它帮人诊断"为什么我对工作失去了热情"。当你问用户"你的自主性打几分？胜任感打几分？关系感打几分？"——最低的那一项，就是当前最需要解决的问题。它把"我不喜欢我的工作"从一个模糊的感觉，变成了三个可诊断、可改善的维度。

---

## 15. PERMA 幸福感模型

### 为什么产生？

Martin Seligman 在创立积极心理学后，发现**"幸福"这个词太模糊了**——它可能是"开心"（积极情绪），也可能是"有意义"（超越自我），也可能是"投入"（心流）。他需要一种方式，把"幸福"拆解成可测量、可改善的维度。

**要解决的问题**：什么是真正的幸福？如何帮人评估和提升自己的幸福感，而不只是"减少痛苦"？

### 底层假设

1. 幸福不是单一维度，而是五个维度的组合：积极情绪、投入、关系、意义、成就
2. 不同的人在这五个维度上的权重不同——有人靠"关系"获得幸福，有人靠"成就"
3. 传统心理学关注"如何减少痛苦"，PERMA 关注"如何增加幸福"
4. 减少痛苦 ≠ 增加幸福——两者需要不同的策略

### 为什么能帮人解决问题？

它帮人回答"我为什么觉得不开心"——不是因为你有什么问题，而是因为某个维度长期被忽视。比如一个把所有精力放在"成就"上的人，可能在"关系"和"积极情绪"维度上得分很低。PERMA 让你看到全景，然后选择优先改善哪个维度。

---

## 16. 刺猬概念 (Hedgehog Concept)

### 为什么产生？

Jim Collins 在研究"从优秀到卓越"的公司时发现，**那些实现跨越式发展的公司，都找到了一个"刺猬概念"——他们专注于一件事，并把它做到极致**。而那些"狐狸型"公司（什么都做、什么都尝试），反而表现平平。

**要解决的问题**：为什么有些公司（和个人）能实现跨越式发展，而大多数不能？如何找到那个"你该专注的一件事"？

### 底层假设

1. 卓越来自于"聚焦"，而不是"分散"——找到你的刺猬概念，然后只做那一件事
2. 刺猬概念 = 热情 × 能力 × 经济引擎的交集——三个都满足，才是真正的方向
3. 大多数人分散精力在太多事情上，而刺猬型的人把所有精力集中在一个点上
4. 找到刺猬概念需要时间——它不是一次顿悟，而是反复试错的结果

### 为什么能帮人解决问题？

它帮人从"我有很多想法但不知道做哪个"到"这就是我该专注的事"。尤其是创业者，经常被各种机会分散注意力。刺猬概念像一个过滤器：这件事在我的热情、能力和经济引擎的交集里吗？不在？那就先不做。

---

## 17. SCARF 模型

### 为什么产生？

David Rock 在 2008 年发现，**神经科学的研究表明，社交威胁和物理威胁会激活大脑的同一区域**。也就是说，被老板当众批评，和被人打了一拳，大脑的反应是类似的。他由此提出了 SCARF 模型，解释为什么职场中的某些事会让人产生强烈的"威胁反应"。

**要解决的问题**：为什么有些人在某些工作环境中极度不适，而另一些人完全不在意？如何理解和预测人的社交反应？

### 底层假设

1. 大脑把社交威胁和物理威胁当成同一件事——被排斥、被轻视、被不公平对待，都会触发"战斗或逃跑"反应
2. 五个社交维度（地位、确定性、自主性、关系、公平）决定了人的社交舒适度
3. 每个人对五个维度的敏感度不同——有人对"不公平"极度敏感，有人对"不确定"极度敏感
4. 理解自己的 SCARF 敏感度，可以帮你选择适合自己的环境，而不是一直"硬扛"

### 为什么能帮人解决问题？

它帮人理解"为什么我在这家公司这么难受"——不是因为工作本身不好，而是因为 SCARF 维度不匹配。一个高自主性需求的人，在 micro-manage 的环境里会崩溃。一个高确定性需求的人，在创业公司会焦虑。SCARF 让你看到：你的不适不是因为"你不够好"，而是因为"环境不适合你"。

## 18. 理解六层次 (Logical Levels)

### 为什么产生？

Robert Dilts 在 NLP 研究中发现，**很多人在解决问题时，一直在错误的层次上努力**。比如想减肥的人，一直在行为层（节食、运动）努力，但问题在身份层（"我是一个不自律的人"）。只要身份层的认知不变，行为层的努力就会被身份层抵消。

**要解决的问题**：为什么有些人反复尝试改变但总是失败？如何找到"真正需要改变"的那个层次？

### 底层假设

1. 人的思维存在层级结构——环境→行为→能力→信念/价值观→身份→精神
2. 上层定义下层——身份层的改变，会自然引发下层（行为、环境）的改变
3. 在低层解决高层问题是徒劳的——就像试图通过粉刷外墙来修复地基裂缝
4. 环境是最容易改变但影响最小的，身份是最难改变但影响最大的

### 为什么能帮人解决问题？

它帮人回答"为什么我试了这么多方法都没用"。当你发现你一直在行为层努力（"我要更努力"），但问题在身份层（"我不是做这个的人"）——你就知道需要换一个方向。六层次让你从"更努力地做同一件事"转向"做一件不同的事"。

## 19. AQAL 整合理论

### 为什么产生？

Ken Wilber 在整合几百种心理学、哲学、灵性理论时发现，**大多数理论只看到现实的某一个象限，而忽略了其他象限**。他提出了 AQAL（All Quadrants All Levels）框架，试图建立一个"所有理论的地图"——不是要取代任何理论，而是要帮人看到每个理论在整个地图上的位置。

**要解决的问题**：为什么不同的心理学模型会给出不同的结论？如何整合这些不同的视角，而不是"选一个对的"？

### 底层假设

1. 任何现象都可以从四个象限来看：个体-内在（心理）、个体-外在（行为）、集体-内在（文化）、集体-外在（系统）
2. 大多数理论只覆盖一个或两个象限——MBTI 在个体-内在，DISC 在个体-外在，螺旋动力学在集体-内在
3. 不同象限的"真相"不同，但都是"真相"——它们不是矛盾的，而是互补的
4. 整合不是"选一个对的"，而是"看到全景"

### 为什么能帮人解决问题？

它帮人理解"为什么 MBTI 说我是这样，DISC 说我是那样，两者不矛盾"。因为 MBTI 在看你的内心世界（个体-内在），DISC 在看你的外在表现（个体-外在）。AQAL 让你看到：不同模型是不同角度的镜头，合在一起才能看到完整的你。

## 总结：底层逻辑的三大共性

看完 19 个模型的底层逻辑，你会发现三个共同点：

### 1. 每个模型都在回答一个"为什么"

| 模型 | 要回答的核心问题 |
|------|-----------------|
| 心流 | 为什么做有些事忘了时间？ |
| MBTI | 为什么同一件事有人轻松有人痛苦？ |
| CliftonStrengths | 为什么不研究人"哪里做对了"？ |
| DISC | 为什么人和人合作方式不同？ |
| VIA | 什么是跨文化的"好"？ |
| 霍兰德 | 为什么高薪工作让人痛苦？ |
| 九型 | 为什么我总是一样地"犯错"？ |
| 螺旋动力学 | 为什么价值观会变？ |
| Ikigai | 为什么有些人活得久且快乐？ |
| 叙事身份 | 为什么经历相似的人感受不同？ |
| 可能自我 | 为什么有些人有动力有人没有？ |
| 变革免疫 | 为什么聪明人改不了？ |
| 乔哈里窗 | 为什么别人看我和我自己看我不一样？ |
| 自我决定 | 为什么内在动机会消失？ |
| PERMA | 幸福到底是什么？ |
| 刺猬概念 | 为什么聚焦比分散更有效？ |
| SCARF | 为什么社交不适和物理疼痛一样？ |
| 六层次 | 为什么在错误层次努力会失败？ |
| AQAL | 为什么不同模型给出不同结论？ |

### 2. 每个模型都是一面"透镜"

模型不是"真相"，而是"看真相的角度"。没有一个模型能告诉你"你是谁"，但每个模型都能帮你看到自己的一个侧面。教练的工作不是选一个对的模型，而是根据用户的问题，选择最合适的透镜。

### 3. 知道"为什么"才能知道"什么时候用"

理解一个模型的底层逻辑，你就知道：
- **什么时候该用**：用户的问题和模型要回答的问题匹配时
- **什么时候不该用**：用户的问题不在这个模型的能力范围内
- **怎么和其他模型配合**：这个模型看到什么，看不到什么，需要哪个模型来补
