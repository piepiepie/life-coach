# 克利夫顿优势（CliftonStrengths / 原盖洛普优势识别器）

## 模型概述

盖洛普克利夫顿优势评估（CliftonStrengths，原 StrengthsFinder）由 Donald O. Clifton 开发，被誉为"优势心理学之父"。该模型基于一个核心理念：每个人最大的成长空间不在于弥补短板，而在于充分发挥其最擅长的领域。模型定义了 34 种天赋主题，分为 4 大领域。

---

## 34 种天赋主题 × 4 大领域

### 领域一：执行力（Executing）——让事情发生的能力

| 天赋主题 | 简要描述 |
|---------|---------|
| **成就（Achiever）** | 内在驱动力强，每天都要有产出和成就感 |
| **统筹（Arranger）** | 善于协调多变量，像下棋一样组织资源和人员 |
| **信仰（Belief）** | 拥有不变的核心价值观，以此为行为准则 |
| **公平（Consistency）** | 重视规则和公平，一视同仁地对待每个人 |
| **审慎（Deliberative）** | 做决定前仔细评估风险，行事谨慎 |
| **纪律（Discipline）** | 喜欢结构和秩序，按计划行事 |
| **专注（Focus）** | 设定明确方向，排除干扰，直奔目标 |
| **责任（Responsibility）** | 对承诺的事情有强烈的心理所有权 |
| **排难（Restorative）** | 善于发现问题并解决问题，享受"修复"的乐趣 |

### 领域二：影响力（Influencing）——掌控局面、表达观点的能力

| 天赋主题 | 简要描述 |
|---------|---------|
| **行动（Activator）** | 将想法转化为行动，不耐烦等待，喜欢立刻开始 |
| **统率（Command）** | 敢于掌控局面，愿意承担领导责任和直面冲突 |
| **沟通（Communication）** | 善于用语言生动表达，让想法引人入胜 |
| **竞争（Competition）** | 喜欢与他人比较，追求第一 |
| **完美（Maximizer）** | 追求卓越，从优秀到卓越而非从弱到强 |
| **自信（Self-Assurance）** | 对自身能力和管理生活的信心很强 |
| **追求（Significance）** | 希望在他人眼中非常重要，渴望被认可 |
| **取悦（Woo）** | 喜欢结识新人并赢得他们的好感 |

### 领域三：关系建立（Relationship Building）——凝聚团队的能力

| 天赋主题 | 简要描述 |
|---------|---------|
| **适应（Adaptability）** | 活在当下，随遇而安，灵活应对变化 |
| **伯乐（Developer）** | 善于发现他人的潜力并享受培养他人的过程 |
| **关联（Connectedness）** | 相信万物相互关联，有强烈的归属感 |
| **体谅（Empathy）** | 能感知他人的情绪，站在对方角度看问题 |
| **和谐（Harmony）** | 寻求共识，避免冲突，促进团队协作 |
| **包容（Includer）** | 接纳边缘人群，确保每个人都被纳入 |
| **个别（Individualization）** | 对每个人的独特之处敏感，懂得因材施教 |
| **积极（Positivity）** | 富有感染力，乐观向上，给人带来正能量 |
| **交往（Relator）** | 享受深度关系，与少数人建立深厚信任 |

### 领域四：战略思维（Strategic Thinking）——吸收、分析信息并做出更好决策的能力

| 天赋主题 | 简要描述 |
|---------|---------|
| **分析（Analytical）** | 寻找原因和证据，要求数据支撑 |
| **回顾（Context）** | 通过回顾过去理解现在，重视历史背景 |
| **前瞻（Futuristic）** | 迷恋未来，善于用愿景激励他人 |
| **理念（Ideation）** | 善于发现事物之间的联系，想法层出不穷 |
| **搜集（Input）** | 有强烈的好奇心，喜欢收集和归档信息 |
| **思维（Intellection）** | 喜欢深入思考，享受智力活动和独处反思 |
| **学习（Learner）** | 享受学习过程本身，而非结果 |
| **战略（Strategic）** | 能快速发现相关模式，想出任选方案和最佳路径 |

## 核心理念：天赋 × 投入 = 优势

### 天赋（Talent）

天赋是自然而然的思维、感受或行为模式。它是"原材料"，可以被测评但不能被教授。天赋表现为：
- 对某些活动的自然渴望
- 做某些事时的快速学习能力
- 做某些事时的高度满足感
- 反复出现的思维和行为模式

### 投入（Investment）

投入是将天赋转化为优势所需的时间和精力，包括：
- 刻意练习和学习
- 获得相关知识和技能
- 积累经验

### 优势（Strength）

优势=天赋×投入。优势是在特定领域持续产出近乎完美表现的能力。仅仅有天赋而不投入，无法形成真正的优势。

---

## 如何在对话中识别天赋

作为教练，你可以通过以下维度观察和识别用户的天赋模式：

1. **渴望（Yearning）**：用户被什么类型的事情自然吸引？他们反复提到想做什么？
2. **快速学习（Rapid Learning）**：用户在哪些领域学得比别人快？
3. **心流（Flow）**：什么活动让用户忘记时间、自动进入深度投入状态？
4. **满足感（Satisfaction）**：完成什么任务后用户感到特别充实和满足？
5. **自动行为（Glimpses of Excellence）**：用户在不经意间表现出色的时刻，往往就是天赋的体现。

## 各领域天赋主题的职业启示

- **执行力主题突出**：适合需要高效产出、项目管理和运营执行的岗位（运营经理、项目管理、审计、供应链管理）。
- **影响力主题突出**：适合需要说服、激励和推动他人行动的角色（销售、市场、公关、创业、政治）。
- **关系建立主题突出**：适合需要深度人际连接和团队凝聚的角色（HR、心理咨询、护理、教育、客户成功）。
- **战略思维主题突出**：适合需要深度分析和前瞻性规划的角色（战略规划、数据分析、研究、产品战略）。

---

## 教练应用注意事项

1. **关注前 5-10 个主题，而非 34 个全部**：排在最前面的主题代表了用户最自然的思维和行为模式。
2. **主题组合比单个主题更重要**：例如，"分析"+"战略"+"前瞻"的组合与"分析"+"审慎"+"纪律"的组合，导向完全不同的职业方向。
3. **弱势主题不必过分关注**：该模型的核心哲学是"管理弱势，发展优势"。只有当弱势成为障碍时才需要管理。
4. **避免类型化思维**：34 个主题的组合可能性极大（前 5 个就有超过 3300 万种组合），不要将用户简单归类。
5. **优势的"阴暗面"**：任何优势在过度使用或在不恰当的场合使用时都可能成为障碍。例如，"行动"天赋可能导致冲动，"审慎"天赋可能导致过度保守。
