# Ikigai（生き甲斐 / 活着的理由）

## 模型概述

Ikigai 来自日本冲绳，意为"活着的理由"或"每天早晨起床的动力"。它由四个维度的交集构成，帮助用户找到真正有意义、可持续的事业方向。

## 四个维度

```
       你热爱的          你擅长的
         (Passion)        (Profession)
            \              /
             \            /
              \          /
               \        /
        (Mission)\      /(Vocation)
                  \    /
                   \  /
                    \/
                    /\
                   /  \
                  /    \
         (Dharma)/      \(Utility)
                /        \
               /          \
              /            \
             /              \
    世界需要的           你能获得报酬的
```

### 1. 你热爱的 (What You Love)
- **探测信号**：心流时刻、忘了时间的事、不计报酬也愿意做的事
- **小切口问题**：
  - "你最近一次忘了时间是在做什么？"
  - "如果钱不是问题，明天你会做什么？"
  - "你手机里最近下载的 app 是什么？为什么下载？"

### 2. 你擅长的 (What You Are Good At)
- **探测信号**：别人找你帮忙的事、学得比别人快的事、做起来轻松的事
- **小切口问题**：
  - "有没有什么事，你做起来觉得特别轻松，但别人说'你好厉害'？"
  - "别人经常因为什么事来找你帮忙？"
  - "你最近一次教别人做一件事，是什么？"

### 3. 世界需要的 (What The World Needs)
- **探测信号**：用户看到的社会问题、想要改变的事情、觉得"不应该这样"的事
- **小切口问题**：
  - "你最近一次觉得'这个世界不应该这样'是什么事？"
  - "如果给你一个魔法棒，可以改变世界上的一件事，你会改变什么？"
  - "你觉得这个世界最缺什么？"

### 4. 你能获得报酬的 (What You Can Be Paid For)
- **探测信号**：用户已有的收入来源、被市场认可的技能、商业模式的可行性
- **小切口问题**：
  - "你最近一次因为做了什么事而收到钱？"
  - "有没有什么事，你本来觉得'这也能赚钱？'但后来发现真的可以？"
  - "你上一次觉得'这个钱花得值'是买了什么？反过来，你觉得什么'不值这个价'？"

## 四维交集解读

| 交集 | 含义 | 教练引导 |
|------|------|----------|
| 热爱 ∩ 擅长 = **激情 (Passion)** | 你享受且擅长，但可能无法变现或不被需要 | "你享受这个过程，但你需要考虑如何让它对别人有价值" |
| 热爱 ∩ 被需要 = **使命 (Mission)** | 你做的是重要的事，但可能不擅长或无法变现 | "你的心是对的，但你需要提升相应的能力" |
| 擅长 ∩ 能赚钱 = **职业 (Profession)** | 你能靠这个谋生，但可能不热爱或不觉得有意义 | "你能靠这个赚钱，但十年后你还会想做吗？" |
| 被需要 ∩ 能赚钱 = **职业 (Vocation)** | 你做的是有用的且能赚钱的，但可能不热爱或不擅长 | "这对世界有用，但对你的内心呢？" |
| 四个都满足 = **Ikigai** | 理想状态 | 很少一蹴而就，通常是一个逐步逼近的过程 |

## 教练使用指南

### 流程
1. 分别探测四个维度，记录每个维度的发现
2. 找出已经在 Ikigai 中心附近的活动
3. 识别"靠近但差一点"的方向——只差一个维度就能进入中心
4. 制定行动计划：如何补上缺失的那个维度

### 注意事项
- Ikigai 不是一次性找到的，是逐步逼近的
- 不同人生阶段，四个维度的内容会变化
- 不必追求完美交集——有时"靠近中心"就已经很好了
- 关注"你在向哪个方向移动"，而非"你现在在哪里"
