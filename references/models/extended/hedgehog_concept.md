# 刺猬概念 (Hedgehog Concept)

> ⚠️ **话术标注说明**：本文中的"小切口问题"、示例问句、教练引导语、信号提示等，均为**示例与风格参考**，仅供方向指引。请基于用户当下的实际处境**自然化用、改写、替换**，不要逐字照搬或机械重复。模型的层次/类型定义与核心原则请保留。

## 模型概述

刺猬概念来自 Jim Collins 的《从优秀到卓越》，基于 Isaiah Berlin 的"刺猬与狐狸"比喻。它帮助个人和组织找到"一件事"——你在这个交集上能做到世界最好。对于创业者来说，这是找到核心方向的有力工具。

## 三个圆圈的交集

```
        你对什么充满热情
       (What You Are Deeply
         Passionate About)
              \
               \
                \
                 \    ★ 刺猬概念
                  \  (你该专注的一件事)
                   \
                    \
      ┌──────────────┼──────────────┐
      │              │              │
你在什么方面          什么驱动你的
能成为世界最好          经济引擎
(What You Can Be    (What Drives Your
Best In The World   Economic Engine
      At)                )
```

### 圆圈 1：你对什么充满热情
- 不是"你喜欢什么"，而是"你深深在乎什么"
- 探测：什么让你早上愿意起床？什么让你愤怒或兴奋？
- **小切口问题**：
  - "有没有什么事情，你做的时候感觉不到累？"
  - "你最近一次因为'太对了'而激动，是什么事？"
  - "如果钱不是问题，你会把时间花在什么上面？"

### 圆圈 2：你在什么方面能成为世界最好
- 不是"你擅长什么"，而是"你可能在什么方面成为世界最好"
- 关键是：你的天赋 + 你的投入 + 你独特的经历组合
- **小切口问题**：
  - "有没有什么事，你做起来觉得特别轻松，但别人觉得很难？"
  - "你独特的经历组合是什么？有哪些事是'只有你'同时具备的？"
  - "如果有一个领域，你投入十年，你觉得自己能成为什么样的人？"

### 圆圈 3：什么驱动你的经济引擎
- 不是"什么能赚钱"，而是"什么能持续赚钱"
- 关键是：找到你的"单一经济指标"——每 X 产生多少利润
- **小切口问题**：
  - "你之前赚钱的经历里，哪个是最'舒服'的赚钱方式？"
  - "你觉得自己提供的价值，别人愿意为什么买单？"
  - "如果要把你的时间/能力变成一个产品，你卖什么？怎么定价？"

## 何时激活

- 创业方向选择（模式 7：场景模拟）
- 职业转型时，需要找到一个"聚焦点"
- 用户有多个方向但无法决定哪个是最核心的
- 用户需要一个"一句话说清楚自己在做什么"的定位

## 教练使用指南

### 刺猬 vs 狐狸
- **刺猬**：专注一件事，做到极致，用一个简单的理念理解复杂世界
- **狐狸**：知道很多事，灵活多变，用多种策略应对复杂世界
- 刺猬概念不是否定狐狸——而是帮你在"要做的事"上找到聚焦点

### 三个圆圈的常见问题
- **只有圆圈 1+2（热情+能力），没有 3（经济引擎）**：这是爱好，不是事业。需要找到变现方式。
- **只有圆圈 1+3（热情+赚钱），没有 2（能力）**：这是梦想，需要长期投入提升能力。
- **只有圆圈 2+3（能力+赚钱），没有 1（热情）**：这是谋生，长期可能 burnout。
- **三个圆圈都有**：这就是你该专注的方向。

### 对创业者的特别价值
- 刺猬概念帮用户回答："我到底在做什么？"
- 如果用户无法用一句话说清楚自己的商业模式，大概率三个圆圈还没对齐
- 刺猬概念的"单一经济指标"帮助用户聚焦核心指标，而不是什么都要

### 与 Ikigai 的区别
| 维度 | Ikigai | 刺猬概念 |
|------|--------|---------|
| 目的 | 找到活着的意义 | 找到事业的核心聚焦点 |
| 适用场景 | 人生整体方向 | 创业/事业策略 |
| 经济维度 | "你能获得报酬吗" | "什么驱动你的经济引擎" |
| 能力维度 | "你擅长什么" | "你能在什么方面成为世界最好" |
| 核心差异 | 更偏向"内心的满足" | 更偏向"外部的卓越" |
