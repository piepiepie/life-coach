# 乔哈里窗 (Johari Window)

## 模型概述

乔哈里窗由 Joseph Luft 和 Harry Ingham 提出，用于理解自我认知和人际沟通。它将自我认知分为四个区域，帮助用户看到"自己知道"和"自己不知道"、"别人知道"和"别人不知道"的交叉地带。

## 四个区域

```
                自己知道            自己不知道
       ┌──────────────────┬──────────────────┐
别人知道│   公开区 (Open)    │  盲区 (Blind Spot) │
       │   自己知道+别人知道  │  别人知道+自己不知道 │
       ├──────────────────┼──────────────────┤
别人不  │   隐藏区 (Hidden)   │  未知区 (Unknown)   │
知道   │   自己知道+别人不知道│  自己不知道+别人不知道│
       └──────────────────┴──────────────────┘
```

### 1. 公开区 (Open/Arena)
- 自己知道、别人也知道的部分
- 例：你的职业、你的公开行为、你主动分享的信息
- **目标**：扩大公开区，增加透明度和信任

### 2. 盲区 (Blind Spot)
- 别人知道、但自己不知道的部分
- 例：你的某些行为模式、别人对你的真实看法、你没意识到的优势
- **目标**：通过反馈缩小盲区

### 3. 隐藏区 (Hidden/Façade)
- 自己知道、但别人不知道的部分
- 例：你的不安全感、你的真实想法、你没说出口的渴望
- **目标**：适度分享，让值得信任的人进入隐藏区

### 4. 未知区 (Unknown)
- 自己不知道、别人也不知道的部分
- 例：未被开发的潜能、潜意识中的模式、未来的可能性
- **目标**：通过探索和体验发现未知区

## 何时激活

- 探索 L8（盲区）
- 用户说"我觉得自己挺好的，但别人不这么看"——盲区和公开区的差距
- 用户问"别人怎么看我"——帮助扩大公开区
- 用户需要团队反馈时

## 小切口问题

**"盲区"探测**：
- "有没有什么事情，别人对你的看法和你对自己的看法不一样？"
- "你最近一次收到一条让你意外的反馈是什么？别人说了什么？"
- "你有没有过'我觉得我做得挺好的，但别人不这么觉得'的经历？反过来呢？"
- "你觉得你身边最了解你的人，会说你'最大的毛病'是什么？"

**"隐藏区"探测**：
- "有没有什么事情，你从来没跟任何人说过？"
- "你在工作中和在家里，是两个不同的人吗？哪里不一样？"
- "你有没有一个'只有自己知道'的梦想？"

**"未知区"探测**：
- "有没有什么事情，你从来没试过，但隐隐觉得'我可能会擅长'？"
- "如果让你尝试一个你从来没做过的事情，你会选什么？"
- "你觉得你身上有什么东西，还没有被完全发挥出来？"

## 教练使用指南

### 反馈桥梁
- 当用户收到他人反馈时，帮助用户区分"事实"和"解读"
- 多个独立来源指向同一件事 → 大概率是盲区的真实内容
- 单一来源的反馈 → 可能是对方的主观看法，也可能是真实信号

### 盲区探索的安全原则
- 不要在用户还没准备好时强行打开盲区
- 先肯定用户已经看到的，再温柔地指出可能没看到的
- 用"可能"而非"确定"的语言
- 例："我注意到一个模式，可能你自己没注意到——你想听听吗？"

### 与冰山模型整合
- 公开区 → L1-L2（水面之上）
- 盲区 → L8（盲区）
- 隐藏区 → L5-L6（身份、深层需求）
- 未知区 → L7（潜能与愿景）

### 盲区信号识别
- 用户反复遇到同样的问题，但归因于"运气不好"或"别人有问题"
- 用户的自我描述和教练观察到的行为模式明显不一致
- 用户说"别人都说我 X，但我不觉得"
- 用户能用复杂理论分析别人，但很少分析自己
