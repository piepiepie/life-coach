# 理解六层次 (Logical Levels / Neurological Levels)

> ⚠️ **话术标注说明**：本文中的示例问句、场景话术、信号提示等，均为**示例与风格参考**，仅供方向指引。请基于用户当下的实际处境**自然化用、改写、替换**，不要逐字照搬或机械重复。六层次的层次定义与"上层驱动下层"等核心原则（方法论护栏）请保留原文。

## 模型概述

理解六层次由 Robert Dilts 提出，源于 NLP（神经语言程序学），描述了人类思维和改变的六个层次。**核心洞见：上层的一个小改变，会引发下层的大变化。反过来，在下层努力解决上层的问题，往往是徒劳的。**

## 六个层次（从下到上）

```
  6. 精神/系统 (Spirituality/Purpose)
     "我为谁？为了什么？"
     — 人生使命、超越自我的意义
    ─────────────────────────────────
  5. 身份 (Identity)
     "我是谁？"
     — 自我认知、角色定位
    ─────────────────────────────────
  4. 信念/价值观 (Beliefs/Values)
     "为什么？什么对我重要？"
     — 信念系统、核心价值观
    ─────────────────────────────────
  3. 能力 (Capability)
     "我怎么做？我有什么能力？"
     — 技能、策略、思维方式
    ─────────────────────────────────
  2. 行为 (Behavior)
     "我做了什么？"
     — 具体行动、习惯
    ─────────────────────────────────
  1. 环境 (Environment)
     "在哪里？什么时候？和谁？"
     — 外部条件、时间、地点、人
```

## 核心原则：上层驱动下层

**一个关键教练原则**：在哪个层次产生的问题，就应该在哪个层次（或更高层次）解决。

> ⚠️ 下表"正确做法"列中的示例问句为方向参考，自然化用即可，不必逐字。

| 场景 | 错误做法（在低层解决高层问题） | 正确做法（在对应层次解决） |
|------|------------------------------|--------------------------|
| 用户说"我觉得自己不适合做管理" | 送他去上管理课（能力层） | 探索他的身份认知——"你觉得'管理者'是什么样的人？你觉得自己是吗？"（身份层） |
| 用户说"我每天加班但升不上去" | 教他时间管理技巧（行为层） | 探索他的信念——"你觉得'努力'和'升职'之间是什么关系？"（信念层） |
| 用户说"我不喜欢现在的工作" | 帮他改简历（行为层） | 探索他的价值观——"什么工作让你觉得'值了'？"（价值观层） |
| 用户说"我想换个环境" | 帮他找新公司（环境层） | 先检查是不是上层的问题——"换环境能解决吗？还是问题在别的地方？" |

## 何时激活

- 用户反复在同一个问题上打转，尝试了各种方法但无效 → 可能在下层解决上层问题
- 用户说"我试过了，没用" → 检查是否在正确的层次上干预
- 用户说"我觉得自己不行" → 可能是身份层的问题，需要从身份层解决
- 用户说"环境不好/同事不好/老板不好" → 检查是否在环境层归因，忽略了上层
- 做教练对话时，需要判断"当前问题卡在哪个层次"

## 六层次探测问题

### 环境层（Where? When? With whom?）
- "你最近一次觉得'不舒服'是在什么场景下？在哪里？和谁在一起？"
- "你现在的公司/团队/环境里，最让你满意的是什么？最不满意的呢？"
- "如果换一个环境，你觉得什么会不一样？"

### 行为层（What?）
- "你最近一周做了哪些事情？你的一天是怎么过的？"
- "你做了什么来改变现状？"
- "你每天花最多时间在什么事情上？"

### 能力层（How?）
- "你觉得你做这件事的能力怎么样？"
- "你最近学了什么新东西？花了多久上手？"
- "如果让你教别人做这件事，你觉得你能教好吗？"

### 信念/价值观层（Why?）
- "你最近一次觉得'这不对'是什么事？"
- "你觉得'成功'是什么？你这个想法是从哪里来的？"
- "有没有什么想法，一直在限制你？比如'我不够好'、'我不配'、'我做不到'？"

### 身份层（Who?）
- "如果不用'我在 XX 公司做 XX'来介绍自己，你会怎么说？"
- "你觉得你是一个什么样的人？这个描述你满意吗？"
- "你最近一次觉得'我不是这样的人'是什么事？"

### 精神/系统层（For whom/what?）
- "你觉得你做的事，对别人有什么影响？"
- "如果有一天你离开了，你希望别人记住你什么？"
- "你觉得有什么东西是'比你自己更大'的？你属于那个更大的东西吗？"

## 教练使用指南

### 问题定位法（核心教练技术）

当用户提出一个问题时，先判断问题卡在哪个层次：

1. **听用户的语言**——用户的语言会自然落在某个层次
   - "我没时间" → 环境层
   - "我不知道怎么做" → 能力层
   - "我觉得这不公平" → 信念/价值观层
   - "我不是做这个的料" → 身份层

2. **向上一层提问**——下层的答案往往在上层
   - 用户卡在环境层："你说的这个问题，跟你'做了什么'有关系吗？"（引导到行为层）
   - 用户卡在行为层："你做这件事的时候，觉得自己的能力够吗？"（引导到能力层）
   - 用户卡在能力层："你为什么觉得学不会？是能力问题，还是你觉得自己'不是学这个的人'？"（引导到身份层）

3. **从上层赋能下层**——改变上层认知，下层行为自然改变
   - 例：不是教用户"怎么管理时间"（能力层），而是帮用户想清楚"我为什么要把时间花在这件事上"（价值观层）或"我想成为一个什么样的人"（身份层）

### 常见教练场景

**场景 1：用户说"我想换个工作"（环境层）**
- 不要直接帮用户分析"哪个公司好"（环境层解决环境层问题）
- 先问："你为什么想换？是环境的问题，还是你做的事情的问题？"（行为层）
- 再问："如果换一个环境，但你还是做同样的事，你觉得会不一样吗？"（检查是否在低层解决高层问题）
- 最终可能要问到："你想成为什么样的人？这个方向能帮你成为那个人吗？"（身份层）

**场景 2：用户说"我学不会"（能力层）**
- 不要直接说"多练习就好了"（能力层解决能力层问题）
- 先问："你觉得自己为什么学不会？是方法不对，还是你觉得自己'不是学这个的料'？"（检查是否身份层问题）
- 如果用户说"我就是学不会技术的东西"——这是身份层问题，需要从身份层解决

**场景 3：用户说"我觉得自己不够好"（身份层）**
- 这是身份层问题，不能从能力层（"你其实很厉害"）或行为层（"你多做几次就好了"）解决
- 应该从身份层探索："你觉得'够好'是什么样子？你这个标准是从哪里来的？"
- 或者从精神层赋能："你觉得你做的这些事，对别人有什么意义？"

### 与冰山模型的对比

| 维度 | 理解六层次 | 冰山模型 |
|------|-----------|----------|
| 视角 | 杠杆视角——上层改变驱动下层 | 深度视角——从表到里逐层潜入 |
| 核心问题 | "问题卡在哪个层次？" | "还有什么是你没看到的？" |
| 教练策略 | 向上引导，用上层赋能下层 | 向下深入，逐层探索 |
| 独特价值 | 帮用户识别"在错误层次解决问题" | 帮用户看到"水面之下的东西" |
| 互补方式 | 六层次帮定位问题层次，冰山帮在该层次深度探索 | 冰山帮发现深层模式，六层次帮判断从哪里干预 |

### 与冰山模型的层次对应

| 六层次 | 冰山层次 | 对应关系 |
|--------|----------|----------|
| 环境 | — | 冰山模型没有明确的环境层，这是六层次独特的贡献 |
| 行为 | L1-L2（行为与技能） | 大致对应 |
| 能力 | L2（技能）+ L3（天赋） | 六层次的"能力"包含技能和天赋 |
| 信念/价值观 | L4（价值观） | 直接对应 |
| 身份 | L5（身份） | 直接对应 |
| 精神/系统 | L7（潜能与愿景） | 大致对应，六层次更强调"超越自我的意义" |

**关键差异**：冰山模型没有"环境层"，而六层次把环境作为最底层。这提醒教练——有些问题真的是环境问题，不需要往深层挖。判断方法：如果换个环境问题就解决了，那就是环境层问题；如果换了环境问题还在，那就需要往上看了。
