# 职业映射

> 本文档将五大模型(Holland、MBTI、CliftonStrengths、DISC、VIA)与职业方向进行系统映射，帮助AI教练在辅导用户时提供基于模型结果的职业方向参考。

---

## 一、使用原则

### 1.1 核心原则：方向而非处方
- 职业映射提供的是"值得探索的方向"，而非"必须从事的职业"
- 人是复杂的，任何模型都无法完全预测职业适配度
- 职业选择受多种因素影响：环境、时机、价值观、生活阶段等
- 映射结果应作为对话起点，而非辅导终点

### 1.2 交叉验证原则
当多个模型指向同一职业方向时，该方向的参考价值更高：
- 3+模型一致 → 强力推荐探索
- 2模型一致 → 建议优先考虑
- 1模型指向 → 可作为备选方向

### 1.3 动态看待原则
- 职业方向会随着个人成长而变化
- 今天的"不适合"可能是明天的"最佳选择"
- 关注发展趋势而非静态定位

### 1.4 差距分析原则（1.3 新增）
映射给出的是"可能的方向"，但**方向 ≠ 路径**。任何方向在被推荐给用户前，**必须**经过差距分析：把用户画像与该方向的真实市场现实对照，显性化三类缺口（**能力缺口 / 时间缺口 / 资金缺口**），并给出**相邻替代方向**。目的不是劝退，而是让"适合你"从一句感觉变成一张可衡量的差距表。具体方法见文末 §九。

## 二、Holland代码 → 职业领域映射

### 2.1 R (实际型) 职业方向
**核心特征：** 动手操作、技术实践、具体成果
**典型职业：**

- 技术员/技师
- 建筑师
- 飞行员
- 农学家/园艺师
- 运动教练
**工作环境偏好：** 实践导向、结果可见、动手操作

### 2.2 I (研究型) 职业方向
**核心特征：** 分析思考、知识探索、解决问题
**典型职业：**
- 科学家/研究员
- 数据分析师
- 医生/医学研究员
- 软件工程师
- 经济学家
- 大学教授
**工作环境偏好：** 独立思考、深度研究、知识驱动

### 2.3 A (艺术型) 职业方向
**核心特征：** 创意表达、审美追求、独特性
**典型职业：**
- 设计师(平面/产品/UI/UX)
- 作家/编剧
- 艺术家/音乐家
- 广告创意
- 建筑师(偏创意)
- 内容创作者
**工作环境偏好：** 自由表达、创意空间、非结构化

### 2.4 S (社会型) 职业方向
**核心特征：** 帮助他人、人际互动、教育发展
**典型职业：**
- 教师/培训师
- 心理咨询师
- 社会工作者
- 护士/医疗人员
- 人力资源
- 教练/导师
**工作环境偏好：** 人际互动、助人成长、团队协作

### 2.5 E (企业型) 职业方向
**核心特征：** 领导管理、说服影响、商业成就
**典型职业：**
- 企业管理者
- 销售/商务
- 创业者
- 律师
- 政治家
- 投资/金融
**工作环境偏好：** 竞争导向、结果驱动、影响力

### 2.6 C (常规型) 职业方向
**核心特征：** 组织管理、规范执行、精确可靠
**典型职业：**
- 会计/审计
- 行政管理人员
- 银行职员
- 数据分析(偏执行)
- 质量控制
- 物流管理
**工作环境偏好：** 结构清晰、流程规范、稳定可预期

## 三、MBTI类型 → 职业倾向映射

### 3.1 分析型 (NT类型: INTJ, INTP, ENTJ, ENTP)
**职业倾向：** 战略思维、系统分析、创新突破
**推荐领域：**
- 战略咨询/管理咨询
- 科技研发/产品管理
- 金融分析/投资
- 学术研究
- 创业/创新管理
**职业价值：** 智力挑战、自主权、创新空间

### 3.2 外交型 (NF类型: INFJ, INFP, ENFJ, ENFP)
**职业倾向：** 人际发展、意义创造、价值表达
**推荐领域：**
- 心理咨询/教练
- 教育培训
- 写作/内容创作
- 非营利/社会企业
- 人力资源/组织发展
**职业价值：** 意义感、成长性、人际连接

### 3.3 守护型 (SJ类型: ISTJ, ISFJ, ESTJ, ESFJ)
**职业倾向：** 稳定执行、组织管理、服务他人
**推荐领域：**
- 行政管理/公共管理
- 医疗护理
- 教育(基础教育)
- 财务/审计
- 执法/军事
**职业价值：** 稳定、秩序、服务、责任

### 3.4 探索型 (SP类型: ISTP, ISFP, ESTP, ESFP)
**职业倾向：** 实践操作、即时反应、灵活应变
**推荐领域：**
- 技术/工程(现场)
- 艺术/表演
- 销售/BD
- 运动/体育
- 应急/消防
**职业价值：** 自由、刺激、实践、当下

## 五、DISC风格 → 工作环境映射

### 5.1 高D (支配型) → 适合环境
- **环境特征：** 挑战性、自主权、结果导向、快速发展
- **偏好角色：** 决策者、领导者、创业者
- **避免环境：** 过于官僚、缺乏自主权、节奏缓慢
- **适配企业：** 创业公司、快速增长的团队、变革中的组织

### 5.2 高I (影响型) → 适合环境
- **环境特征：** 社交活跃、自由开放、创意空间、正面反馈
- **偏好角色：** 发言者、连接者、创意者
- **避免环境：** 孤立工作、严格流程、负面氛围
- **适配企业：** 创意公司、营销团队、媒体、教育

### 5.3 高S (稳健型) → 适合环境
- **环境特征：** 稳定和谐、团队协作、长期发展、可预期
- **偏好角色：** 支持者、协调者、执行者
- **避免环境：** 频繁变动、竞争激烈、冲突频繁
- **适配企业：** 成熟企业、公共服务、医疗、教育

### 5.4 高C (谨慎型) → 适合环境
- **环境特征：** 精确标准、逻辑清晰、专业深度、质量导向
- **偏好角色：** 分析师、专家、质量把控者
- **避免环境：** 模糊不定、缺乏标准、忽视细节
- **适配企业：** 金融、科技、工程、研究机构

## 六、职业类别 × 模型签名

### 6.1 技术/工程
**模型签名：** Holland R+I, MBTI T, Strengths 分析/排难, DISC C
**关键特征：** 逻辑思维、动手能力、问题解决、精确性
**典型方向：** 软件工程师、机械工程师、数据工程师、架构师
**辅导要点：** 注意发展沟通与人际能力，避免技术孤岛

**模型签名：** Holland A, MBTI N+P, VIA 创造力, Strengths 理念, DISC I
**关键特征：** 创新思维、审美敏感、独特性追求、表达欲望
**典型方向：** UI/UX设计师、品牌设计师、创意总监、艺术家
**辅导要点：** 注意创意商业化的能力建设，建立创作纪律

### 6.3 教育/培训
**模型签名：** Holland S, MBTI F+J, VIA 善良, DISC S, Strengths 伯乐
**关键特征：** 育人热情、耐心、结构化表达、共情能力
**典型方向：** 教师、培训师、教育产品经理、课程设计师

**模型签名：** Holland E, DISC D, Strengths 统率/战略, MBTI E+T+J
**关键特征：** 决策力、战略思维、人际影响、结果导向
**典型方向：** CEO、部门负责人、项目经理、团队领导
**辅导要点：** 注意发展共情与倾听能力，平衡任务与关系

**典型方向：** 创始人、独立创业者、自由职业、小企业主
**辅导要点：** 注意建立系统与流程，避免"创始人陷阱"

**关键特征：** 深度分析、逻辑推理、知识驱动、客观性

**典型方向：** 销售代表、客户经理、市场经理、品牌经理

**典型方向：** 行政主管、运营经理、办公室主任、项目协调
**辅导要点：** 注意发展灵活应变能力，在规范中保留弹性

**模型签名：** Holland E+I, MBTI T+J, Strengths 分析/审慎, DISC C

## 七、多模型交叉验证示例

### 示例1: 强技术型
- Holland: I+R (研究+实际) → 技术/工程
- MBTI: INTJ (分析型) → 科技/战略
- Strengths: 分析+战略+学习 → 深度研究
- DISC: 高C (谨慎型) → 精确标准
- VIA: 判断力+洞察力 → 理性分析
- **结论：** 5模型一致指向技术/研究领域，强烈建议深入探索

### 示例2: 强助人型
- Holland: S (社会型) → 教育/医疗
- MBTI: ENFJ (外交型) → 人际发展
- Strengths: 体谅+伯乐+关联 → 关系建设
- DISC: 高S (稳健型) → 稳定支持
- VIA: 善良+爱+社交智慧 → 利他
- **结论：** 5模型一致指向助人领域，强烈建议探索教育/咨询/医疗方向

### 示例3: 混合型
- Holland: E+A (企业+艺术) → 创业
- MBTI: ENTP (探索型) → 创新/创业
- Strengths: 战略+沟通+行动 → 影响力
- DISC: 高D+I (支配+影响) → 领导
- VIA: 创造力+好奇心 → 创新
- **结论：** 模型部分指向创业，部分指向创新，建议探索"企业内部创业"或"创新型管理"角色

## 八、使用注意事项

1. **避免刻板印象**：职业映射是参考，不是限制。每个人都可以在任何领域成功
2. **关注变化趋势**：职业世界正在快速变化，今天的"理想职业"可能明天就变了
3. **尊重个体差异**：同一模型签名背后是不同的个体，不能一概而论
4. **结合实际情况**：职业选择受限于个人的教育背景、地域、经济条件等
5. **鼓励探索**：映射结果应该鼓励用户去探索，而非限制他们的选择
6. **定期回顾**：随着个人成长，职业映射的结果可能发生变化

## 九、差距分析框架（1.3 新增）

> 解决原技能"类型→领域"刻板映射、缺现实校验的问题。本框架在所有方向生成之后、推荐之前**强制**运行。它与 `market_data_protocol.md`（市场现实层）协同：模型给"可能方向"，市场数据给"现实约束"，本框架给"你与方向之间的差距"。

### 9.1 强制注入个人约束（四问）
在推荐任何方向前，AI **必须**先向用户确认或推断以下约束（缺失则明确标注"约束未知，结论为弱建议"）：

| 约束维度 | 含义 | 示例 |
|----------|------|------|
| **城市/地域** | 机会集中地 vs 用户所在地 | 用户在上海 → AI/数据机会多；用户在三四线 → 远程/自由职业更现实 |
| **可投入资本** | 可支撑多久无收入探索 | 6 个月现金垫 vs 必须当月有收入 |
| **学历/证书门槛** | 硬门槛是否满足 | 用户非科班 → 研岗需补作品集证明 |
| **家庭阶段/责任** | 试错成本与弹性 | 育儿期 → 倾向低波动路径；单身 → 可承受高风险转型 |

> 中文语境下，户籍、35 岁节点、父母养老、配偶就业等均为真实变量，须纳入（详见 `chinese_workplace_context.md`）。

### 9.2 三类缺口量化
对每个候选方向，输出一张差距表（拿不到市场数据时，写为"缺口待验证"，不得编造）：

```
【差距分析 · <方向名>】
- 能力缺口：用户现有 → 该岗位要求 的差距（硬技能/软技能/作品）
- 时间缺口：达到可入行所需最短周期（如 3–6 个月）+ 用户可投入时间是否匹配
- 资金缺口：转型期间收入下降/学习成本 vs 用户可支撑资本
- 相邻替代方向：若主方向缺口过大，给出 2 个"门槛更低/更近"的相邻方向
- 置信度：高/中/低（依据：模型一致度 + 市场数据可得性 + 约束清晰度）
```

### 9.3 相邻替代方向生成规则
当主方向缺口≥2 类且较大时，AI **必须**给出相邻方向，而非只说"你不适合"：
- **降级路径**：同一领域但门槛更低的角色（如"AI 产品经理"缺口大 → "AI 产品运营"先切入）
- **复合路径**：原天赋 + 新趋势的复合（如"设计 + AI"→ AI 辅助设计岗）
- **侧翼路径**：相邻行业但复用相同天赋（如"用户研究"→"B 端客户成功"）

### 9.4 与场景模拟、资源推荐的衔接
- 差距分析输出的"主方向 + 相邻方向"直接作为**场景模拟模式**的输入对象。
- "能力缺口"直接转化为**资源推荐/Playbook** 的学习路径起点（见 `career_playbook_template.md`）。
- 若模型方向与市场现实冲突（如模型指向"传统纸媒编辑"且市场显示萎缩），AI 须主动提示并切换到相邻方向。

> **护栏**：差距分析是帮助用户看清现实，不是替用户做放弃决策。最终是否冲刺高缺口方向，由用户结合自身风险偏好决定。
