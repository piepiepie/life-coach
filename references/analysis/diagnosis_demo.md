# 自动诊断演示：从用户对话到模型匹配

> 本文档演示"见微"Skill 如何从用户的一两句话中，自动完成六层次定位、AQAL 象限判断、模型匹配，然后展开对话。

---

## 示例 1：嫉妒与比较

> **用户**：我总是嫉妒别人比我做的好，我在做自己的项目的时候也会想到别人做的比我好，而且是跨行业的，比如有个房产博主做了 1 年多，赚了 100 多万，买了新车，我就觉得他不如我，但是结果又不会骗人，他已经在房产自媒体获得了流量获得了客户，也赚到了钱。而我在这一年的时间里干了 2-3 个项目，没有一个项目做起来，现在依然原地踏步。

### 第一步：六层次定位

**🧠 听用户语言，判断问题卡在哪个层次**

| 用户说的话 | 对应的层次 | 判断 |
|-----------|-----------|------|
| "干了 2-3 个项目" | 行为层 | 用户做了很多事 |
| "没有一个项目做起来" | 行为层 | 行为的结果不如预期 |
| "他不如我" | 信念/价值观层 | 这是一个价值判断——"我比他强，但他的结果比我好" |
| "结果又不会骗人" | 信念层 | 限制性信念：**结果=价值**。如果结果不好，就是我不行 |
| "依然原地踏步" | 身份层 | "我"是一个"原地踏步的人"——身份叙事 |
| "嫉妒别人比我做的好" | 身份层 + SCARF | 地位威胁 + 身份比较 |

**🎯 六层次判断结论**：

用户表面在说行为层的事（"做了 2-3 个项目没起来"），但真正卡住的地方在**信念层和身份层**之间——

- **信念层**："结果=价值"、"别人不如我但结果比我好=这个世界不公平"
- **身份层**："我是原地踏步的人"、"我是失败者"

**⚠️ 如果只在行为层回应（"你做了什么项目？要不要我帮你分析一下？"）——这是在下层解决上层问题，无效。**

### 第二步：AQAL 象限判断

| 象限 | 内容 |
|------|------|
| **左上（个体-内在）** | 嫉妒、挫败感、自我怀疑、限制性信念"结果=价值" |
| **右上（个体-外在）** | 做了 2-3 个项目、没有收入、看到别人赚了 100 万 |
| **左下（集体-内在）** | 社会文化中"成功的标准"——赚到钱、买新车=成功 |
| **右下（集体-外在）** | 自媒体行业环境、房产博主赛道、跨行业比较 |

**🎯 AQAL 判断**：问题主要在左上（内心世界）和左下（社会价值观内化）。右上（行为）只是结果，不是原因。

### 第三步：模型匹配

| 模型 | 匹配信号 | 用途 |
|------|----------|------|
| **六层次** ✅ | "做了 2-3 个项目"（行为层）vs "原地踏步"（身份层） | 定位：问题在信念层和身份层，不在行为层 |
| **冰山模型** ✅ | 表层是嫉妒，深层是"结果=价值"的信念和"我是失败者"的身份 | 向下潜入：从嫉妒→信念→身份→恐惧 |
| **叙事身份** ✅ | "原地踏步"是一个叙事 | 帮用户看到他在讲什么故事，这个故事可以改写 |
| **变革免疫** ✅ | 做了 2-3 个项目都没起来——为什么？ | 隐藏的假设可能是"如果我不和别人比较，我就没有动力" |
| **SCARF** ✅ | 地位维度被严重威胁 | 帮用户理解嫉妒的神经机制 |
| **可能自我** ✅ | 用户嫉妒的"房产博主"可能是他的"希望自我" | 帮用户区分"羡慕他"和"想成为他" |
| **九型人格** ⚠️ | 比较、嫉妒——可能是类型 3（成就者）信号 | 探索核心恐惧：害怕失败、无价值 |

### 第四步：对话策略

**第一轮：共情 + 六层次定位（不让用户感觉被分析）**

> 教练：这种感觉挺难受的——明明觉得自己不比他差，但他的结果摆在那里。你能跟我说说，当你看到那个房产博主"买了新车"的时候，你心里第一个冒出来的念头是什么？

**🧠 教练意图**：从"嫉妒"这个情绪切入，探测用户的第一反应——是"我也想要"（可能自我）还是"凭什么是他"（信念/SCARF）还是"我怎么就不行"（身份）。

**第二轮：向上引导（从行为层到信念层）**

> 用户：就觉得不公平，他不如我，但结果比我好。
>
> 教练：嗯，"不公平"——你觉得"结果"应该和"能力"成正比，对吗？
>
> 用户：对啊，难道不是吗？
>
> 教练：那如果结果和能力不完全成正比——除了能力，还有什么会影响结果？运气、时机、赛道、坚持的时间……你同意吗？

**🧠 教练意图**：松动"结果=价值"这个限制性信念。不是直接否定，而是让用户自己看到其他因素。

**第三轮：冰山潜入（从信念层到身份层）**

> 用户：……是有这些因素，但一年了，我做了 2-3 个项目都没起来，这怎么解释？
>
> 教练：嗯，一年做了 2-3 个项目——听起来你一直在尝试。但我想问你一个问题：你做第一个项目的时候，是做了多久开始觉得"不行，得换一个"的？
>
> 用户：大概两三个月吧，感觉没什么反馈。
>
> 教练：那个房产博主做了一年多。你给了他一年，但给了自己两三个月。这个差距，你注意到了吗？

**🧠 教练意图**：从"我是失败者"（身份层叙事）引导到具体行为比较——不是能力不行，而是时间不够。松动了"原地踏步"的身份叙事。

**第四轮：叙事重构 + 可能自我探索**

> 教练：我注意到一个模式——你一直在用"别人的结果"来衡量"自己的价值"。但别人的结果是他的一年，你的一年虽然没出结果，但你有 2-3 个项目的经验。你觉得这一年里，你学到了什么？
>
> 用户：……学到了不能同时做太多事，应该专注一个。
>
> 教练：这是很重要的洞察。那个房产博主，你觉得他这一年里是不是也只专注了房产这一件事？
>
> 用户：……应该是。
>
> 教练：所以问题不是"你不如他"，而是"你的策略是分散的，他的策略是聚焦的"。策略是可以调整的，但"你不如他"是一个身份判断——这两个是完全不同的事。你觉得呢？

**🧠 教练意图**：用叙事重构——把"我是失败者"改成"我的策略需要调整"。同时用可能自我——帮用户看到"专注"这个方向。

## 示例 2：16 年会计，想换活法

> **用户**：我在一个公司的会计岗位干了 16 年了，现在觉得很没有意思，想换个活法，换个行业。

### 第一步：六层次定位

| 用户说的话 | 对应的层次 | 判断 |
|-----------|-----------|------|
| "会计岗位" | 环境层 + 能力层 | 16 年的职业身份和技能 |
| "干了 16 年" | 身份层 | "我是一个做了 16 年会计的人"——这是一个厚重的身份 |
| "很没有意思" | 价值观层 | 当前做的事不再满足价值观 |
| "换个活法" | 身份层 + 精神层 | 不只是换工作，是换一种活法——"换活法"比"换行业"更深刻 |
| "换个行业" | 环境层 | 这是用户提出的"解决方案" |

**🎯 六层次判断结论**：

用户说"换个行业"（环境层），但真正的问题是**意义感缺失**（价值观层/精神层）。"换个活法"暗示用户想要的不只是换工作，而是重新定义"我是谁"和"我为什么活着"。

**⚠️ 如果直接帮用户分析"什么行业适合你"（环境层解决环境层问题），可能帮他换了一个行业，但 16 年后又回到同样的困境。**

### 第二步：AQAL 象限判断

| 象限 | 内容 |
|------|------|
| **左上（个体-内在）** | 意义感缺失、对 16 年身份的倦怠、渴望改变 |
| **右上（个体-外在）** | 会计技能、16 年经验、稳定的收入 |
| **左下（集体-内在）** | "稳定工作"的社会期待、中年转型的社会压力 |
| **右下（集体-外在）** | 会计行业现状、其他行业的进入门槛 |

**🎯 AQAL 判断**：问题主要在左上（意义感）和左下（社会期待）。用户可能一直被"应该稳定"的社会声音驱动，但内心在呼唤改变。

### 第三步：模型匹配

| 模型 | 匹配信号 | 用途 |
|------|----------|------|
| **六层次** ✅ | "换个行业"（环境层）vs "换个活法"（身份/精神层） | 定位：问题在意义感，不在行业 |
| **冰山模型** ✅ | "没意思"是表层，深层是什么？ | 向下潜入：什么才有意思？价值观是什么？ |
| **自我决定理论** ✅ | 16 年后"没意思"——哪种需求受挫了？ | 自主性？胜任感？关系感？还是意义感？ |
| **PERMA** ✅ | "没意思"=投入和意义维度低 | 评估五个维度，找到最低的 |
| **Ikigai** ✅ | 想找新方向 | 热爱×擅长×被需要×赚钱 |
| **霍兰德** ✅ | 会计是 C 型（常规型），但用户可能想转向其他类型 | 探测兴趣类型 |
| **螺旋动力学** ✅ | 16 年稳定（蓝色）→想改变（橙色/绿色过渡） | 价值观演化 |
| **可能自我** ✅ | "换个活法"=想成为不同的自己 | 激活"希望自我" |
| **叙事身份** ✅ | 16 年会计是一个身份叙事，现在想改写 | 帮用户重新讲述"我是谁" |

### 第四步：对话策略

**第一轮：共情 + 探测"没意思"的具体含义**

> 教练：16 年——这不是一个短时间。你最近一次觉得"没意思"是什么时候？在什么场景下？

**🧠 教练意图**：把"没意思"从抽象感觉变成具体时刻。探测是"无聊"（投入维度）、"没有意义"（意义维度）、还是"被控制"（自主性维度）。

**第二轮：向上引导（从环境层到价值观/精神层）**

> 用户：上个月做年终报表的时候，我突然想——我的人生不会就这样了吧。
>
> 教练：嗯，"不会就这样了吧"——这句话很重。你觉得"就这样"最让你受不了的是什么？
>
> 用户：就是……重复，每年做同样的事，没有任何变化。
>
> 教练：你渴望的是"变化"还是"成长"？这两个不太一样——变化可以是换一件事做，成长是你自己变得不一样了。

**🧠 教练意图**：帮用户区分"厌倦重复"（需要变化）和"渴望成长"（需要意义）。前者换环境可能解决，后者需要更深层的改变。

**第三轮：冰山潜入（从价值观到身份到潜能）**

> 用户：……应该是成长吧。我觉得自己这 16 年，除了会计技能，好像没什么成长。
>
> 教练：这 16 年里，有没有哪件事——哪怕是很小的事——让你觉得"这个我做得不错，而且有点意思"？
>
> 用户：……带新人的时候。公司来过几个新人，都是我带的。看着他们从不会到会，我觉得挺有成就感的。
>
> 教练：哦？那你带新人的时候，具体做了什么让你觉得有成就感？

**🧠 教练意图**：从 16 年的"枯燥"中找例外——用户可能没意识到，带新人展现了他的天赋（伯乐/教导）和价值观（帮助他人成长）。

**第四轮：Ikigai + 可能自我探索**

> 教练：我注意到一个事——你做了 16 年会计，但让你觉得"有成就感"的不是"做账做得好"，而是"带新人"。这很有意思。你有没有想过，你在"教别人"这件事上，可能比你想象中更擅长？
>
> 用户：……没想过。我一直觉得会计就是做账，带新人是顺便的事。
>
> 教练：你用了"顺便"这个词——但你觉得"顺便"的事，恰恰是你觉得最有成就感的事。如果让你一天里有更多时间"带人"而不是"做账"，你觉得怎么样？
>
> 用户：那肯定有意思多了。
>
> 教练：那我们就从这里开始——"带人"这件事，除了带新人学会计，还能怎么延伸？比如培训、咨询、做内容教别人？你觉得哪个方向你更心动？

**🧠 教练意图**：用 Ikigai 框架——热爱（带人）、擅长（16 年经验+教学能力）、被需要（新人和企业需要培训）、能赚钱（培训/咨询可以变现）。帮用户从"换个行业"的大问题，聚焦到"带人"这个小切口。

## 诊断流程总结

```
用户输入
    │
    ▼
┌──────────────────────────────────────┐
│ 第 1 步：六层次定位                  │
│ "用户说了什么？问题卡在哪个层次？"     │
│ 关键词：听用户的语言落在哪个层次      │
│ 输出：问题层次 + 真正需要解决的层次    │
└──────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────┐
│ 第 2 步：AQAL 象限判断               │
│ "问题在哪个象限？"                   │
│ 左上（内心）？右上（行为）？          │
│ 左下（文化）？右下（系统）？          │
│ 输出：主导象限 + 被忽略的象限         │
└──────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────┐
│ 第 3 步：模型匹配                     │
│ "哪些模型的底层逻辑和这个问题匹配？"   │
│ 匹配条件：模型要解决的问题 ≈ 用户问题  │
│ 输出：3-5 个匹配模型 + 优先级         │
└──────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────┐
│ 第 4 步：对话策略                     │
│ "第一轮说什么？第二轮怎么引导？"       │
│ 原则：共情→六层次定位→冰山潜入→模型   │
│ 输出：具体对话话术                    │
└──────────────────────────────────────┘
```

---

## 关键原则

1. **六层次永远先于冰山**——先判断问题卡在哪个层次，再决定要不要潜入。如果用户在环境层说"公司太远了"，不要急着潜入冰山问他"你的人生意义是什么"。

2. **模型匹配看"底层逻辑"**——不是看用户说了什么词，而是看用户的问题和模型要解决的问题是否匹配。用户说"嫉妒"→ SCARF（地位威胁）和叙事身份（"我是失败者"的故事）和九型（类型 3 的核心恐惧）。

3. **不要一次用太多模型**——匹配 3-5 个，但第一轮对话中最多引入 1-2 个。模型是镜头，不是子弹——不需要一次全打出去。

4. **对话策略必须"不显山不露水"**——不要让用户感觉到你在"切换模型"。你只是在"换个角度看看"、"我注意到一个模式"、"这让我想到"。
