# 六层次 × 冰山模型：整合教练对话流程

## 一、两个模型的底层逻辑

### 理解六层次的底层逻辑

**为什么会产生这个模型？**

Robert Dilts 在 NLP 研究中发现一个现象：有些人反复尝试改变行为（比如"我要更自律"），但总是失败。他发现**问题不在行为本身，而在行为之上**——如果你认为"我不是一个自律的人"（身份层），那么任何行为层的努力都会被这个身份认知抵消。

**底层假设**：
1. 人的思维存在层级结构，上层定义下层
2. 在低层解决高层的问题是徒劳的——就像试图通过粉刷外墙来修复地基裂缝
3. 改变上层（身份、信念）会自然引发下层（行为、环境）的改变
4. 环境是最容易改变的，但改变环境的影响也最小；身份是最难改变的，但改变身份的影响最大

**为什么能帮人解决问题？**

因为它帮你找到"问题真正卡在哪个层次"。大多数人卡在行为层努力（"我要更努力"），但问题其实在身份层（"我不是做这个的人"）或信念层（"努力也不会有结果"）。六层次让你向上看，找到真正的杠杆点。

---

### 冰山模型的底层逻辑

**为什么会产生这个模型？**

弗洛伊德最早提出"冰山"隐喻——意识只是水面之上的小部分，潜意识才是水面之下的巨大部分。后续心理学（萨提亚、组织行为学等）将这个隐喻发展为多层模型。核心观察：**人表现出来的行为（水面之上）只是冰山一角，真正驱动行为的是水面之下的天赋、价值观、信念、身份、恐惧和渴望。**

**底层假设**：
1. 可见的行为只是冰山一角，不可见的部分才是驱动力
2. 越深层的部分越难被自己看到，但越深层对行为的影响越大
3. 通过对话可以逐层深入，从行为到天赋到价值观到身份到盲区
4. 人对自己深层部分的"无知"是正常的——不是缺陷，而是需要探索

**为什么能帮人解决问题？**

因为它帮你看到"你不知道你知道的东西"。很多人的天赋、价值观、限制性信念都在水面之下，他们自己看不见。冰山对话就像举着灯陪他们潜入水下，帮他们看见那些一直在驱动他们但从未被意识到的部分。

---

### 两个模型的互补关系

| 维度 | 六层次 | 冰山模型 |
|------|--------|----------|
| **核心问题** | "问题卡在哪个层次？" | "还有什么是我没看到的？" |
| **运动方向** | 向上——从低层到高层，找到杠杆点 | 向下——从表层到深层，潜入水下 |
| **教练策略** | 定位 → 向上引导 → 用上层赋能下层 | 潜入 → 逐层探索 → 发现隐藏模式 |
| **独特价值** | 防止在错误层次解决问题 | 防止只看到表面而忽略深层 |
| **最适合** | 用户有明确问题但反复尝试无效 | 用户迷茫、不知道自己要什么、想更了解自己 |

**整合逻辑**：六层次告诉你"往哪看"（问题在哪个层次），冰山告诉你"在这个层次要看多深"（该层次下还有什么隐藏的东西）。

## 二、整合教练对话流程

### 流程总览

```
用户提出问题
      │
      ▼
┌─────────────────────────────────────┐
│ 步骤 1：六层次定位                   │
│ "这个问题卡在哪个层次？"              │
│ 听用户语言 → 判断层次 → 决定方向      │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ 步骤 2：决定运动方向                  │
│ 如果在低层 → 向上引导（六层次杠杆）     │
│ 如果在高层 → 向下潜入（冰山探索）       │
│ 如果在同一层反复卡住 → 先向上再向下     │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ 步骤 3：在该层次进行冰山深度探索       │
│ 从表层行为 → 天赋 → 价值观 → 身份     │
│ → 渴望/恐惧 → 潜能 → 盲区             │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│ 步骤 4：从上层赋能下层                │
│ 用高层的发现，回过来解决低层的问题      │
└─────────────────────────────────────┘
```

## 三、完整对话示例

### 场景：用户说"我想换个工作，现在的工作太累了"

---

#### 步骤 1：六层次定位——"这个问题卡在哪个层次？"

**教练**：你说想换个工作——是觉得现在这个公司不好，还是你做的这个岗位本身让你累？

**用户**：公司还行吧，就是活太多了，天天加班。

**🧠 教练判断**：用户说的是"活太多"、"天天加班"——这是环境层（工作量）和行为层（加班）的语言。但先别急着下结论，继续听。

**教练**：加班到最晚那次，是因为什么？

**用户**：因为一个项目上线，我在改方案。其实不是方案本身难，是我改了好几版，领导都不满意，最后我自己也不知道怎么改了。

**🧠 教练判断**：用户从"活太多"（环境层）滑到了"不知道怎么改"（能力层）。继续听。

**教练**：你自己也不知道怎么改了——是不确定领导想要什么，还是不确定自己能不能做好？

**用户**：都有吧……其实我觉得我可能不太适合做这个。别人做方案好像很快就能抓住重点，我总要想很久。

**🧠 教练判断**：用户说出了"我可能不太适合做这个"——这是**身份层**的语言。六层次告诉我们：用户说"想换工作"（环境层），但真正的问题在身份层（"我不适合做这个"）。**如果只在环境层解决（帮他找新工作），问题会跟着他到下一家公司。**

---

#### 步骤 2：决定运动方向——向上还是向下？

**定位**：问题卡在身份层（"我不适合做这个"）。

**决策**：身份层是高层，需要**向下潜入（冰山探索）**——在这个层次上，用户对自己的认知"我不适合"可能只是冰山一角，下面还有价值观、天赋、恐惧需要探索。

---

#### 步骤 3：冰山深度探索（在身份层向下潜入）

**教练**：你说"别人做方案很快就能抓住重点，我总要想很久"——这个"想很久"的过程，你一般在想什么？

**用户**：我在想各种可能性，这个方案可以这样，也可以那样，每种方案都有利弊……

**教练**：等一下，你说"各种可能性"——这个很有意思。你是在纠结"选哪个"，还是在"想有哪些可能性"？

**用户**：想有哪些可能性。我其实挺享受这个过程的，就是把一个问题的各种可能性都列出来，然后分析。

**教练**：你享受这个过程的时候，感觉是什么样的？

**用户**：就是……很沉浸。有时候一抬头发现过了两个小时。而且我想到的可能性，别人经常说"我没想到"。

**🧠 冰山发现**：
- L1-L2（行为/技能）：做方案、分析可能性
- L3（天赋）：系统性思考、看到多种可能性、别人没想到的你能想到 → **战略思维天赋信号**
- 用户说"享受"+"沉浸"+"忘了时间" → **心流信号**

**教练**：你刚才说"我总要想很久"——但你描述的状态听起来不是"想不出来很痛苦"，而是"想得很深很投入"。这两个感觉完全不一样。你觉得哪个更接近真实的你？

**用户**：……确实是投入。但我之前一直觉得"想太久"是缺点，因为别人都比我快。

**教练**：所以问题不是"你不适合做这个"，而是"你做事的方式和别人不一样，但你一直用别人的标准来衡量自己"。你觉得呢？

**用户**：好像是……我一直觉得"快"才是好，"想太久"就是不行。

**🧠 冰山发现**：
- L4（价值观/信念）：用户有一个限制性信念——"快=好，慢=不好"
- L5（身份）：用户用"别人"的标准来定义自己，导致"我不适合"的身份认知

**教练**：这个"快才是好"的想法，是从哪里来的？

**用户**：……可能是上学的时候吧。考试有时间限制，做不完就是差。后来工作了，领导也总是催。

**教练**：嗯。那如果抛开"快才是好"这个标准，单看你做出来的方案——质量怎么样？

**用户**：其实……质量还可以。上次那个方案，虽然改了好几版，但最后领导说"这个方向是对的"。

**教练**：哦？那你当时什么感觉？

**用户**：挺开心的。但也就开心了一下，因为下一个方案又要开始了……

**🧠 冰山发现**：
- L4（价值观）：用户的价值被肯定了，但他没有"允许自己"享受这个肯定
- L6（深层需求）：用户可能有一个未被满足的需求——"被认可"、"被看见过程的努力而不只是结果"

---

#### 步骤 4：从上层赋能下层

**教练**：我注意到几个模式，想和你确认一下——

1. 你说"想换工作"，但当你描述自己真正投入的时候，你其实在享受"深度思考各种可能性"这个过程——这不是"不适合"，这是天赋。
2. 让你痛苦的不是工作本身，而是"快才是好"这个标准——你一直在用别人的尺子量自己。
3. 你的方案质量其实不差，但你很少允许自己"享受"这个事实——开心一下就过去了。

你觉得这些观察准确吗？

**用户**：……挺准的。特别是第二点，我一直觉得自己太慢了。

**教练**：那我们回到一开始的问题——"想换工作"。如果问题不是"你不适合做这个"，而是"你做事的方式和别人不一样，但你没有找到适合你方式的环境"——那换工作能解决吗？

**用户**：……不一定。如果换到新公司，还是被催，还是用"快"来衡量，那还是一样。

**教练**：对。所以真正需要改变的，不是工作（环境层），甚至不是你的速度（行为层）。而是——你怎么看待自己的"慢"（信念层），以及你愿不愿意承认"深度思考是我的天赋，不是缺点"（身份层）。

**用户**：那我应该怎么做？

**教练**：我们先不跳到"怎么做"——那个是能力层和行为层。在跳到那里之前，我想先确认：你愿意接受"深度思考是你的天赋"这个说法吗？还是你觉得别扭？

**用户**：……有点别扭，但好像又有点道理。

**教练**：别扭在哪里？

**用户**：因为从小到大，没人说过"想太多"是天赋。大家都说"你想太多了"。

**🧠 教练判断**：用户从身份层（"我接受自己是深度思考者"）滑到了环境层（"从小到大没人说过"）。这是六层次的典型应用——环境层的"别人怎么说"正在阻碍身份层的转变。

**教练**：嗯，"从小到大没人说过"——这是一个环境。但你现在已经不是小时候了。你现在的工作环境里，有没有人欣赏你这种"想得深"的能力？

**用户**：……有一个同事，每次我帮她分析问题，她都说"你怎么想到的"。

**教练**：你看，至少有一个。所以不是"没有人"，而是"你更习惯听到那些说你想太多的人"。

**教练**：现在，我想邀请你做一个尝试——如果接下来一周，你把自己当成一个"深度思考者"而不是"太慢的人"，你觉得你会做一件什么不一样的事？

**用户**：……我可能会主动跟领导说，这个方案我需要更多时间，但我会给出更全面的分析。

**教练**：好。你觉得说完之后，最坏的结果是什么？

**用户**：领导说不行，必须快。

**教练**：如果领导说"不行"，那说明什么？

**用户**：说明这个环境不适合我。

**教练**：对。到那时候，"换工作"才是一个真正的选择——不是因为你"不适合"，而是因为你的天赋在这个环境里发挥不出来。这是两个完全不同的问题，你觉得呢？

**用户**：……确实是。我之前一直觉得是自己不行。

**教练**：所以，下周你想试一下吗？

**用户**：好，我试试。

## 四、对话复盘：两个模型如何配合

| 步骤 | 六层次做了什么 | 冰山模型做了什么 |
|------|---------------|-----------------|
| 1 | 定位：用户说"换工作"（环境层），但深层语言暴露问题在身份层 | — |
| 2 | 决策：身份层是高层，需要向下潜入，不做环境层的"帮你找新工作" | — |
| 3 | — | 向下潜入：行为→天赋（心流信号）→信念（"快才好"）→身份（"我不适合"）→深层需求（"被认可"） |
| 4 | 从上层赋能下层：改变身份认知（"深度思考是天赋"）→ 改变信念（"快≠好"）→ 改变行为（"主动沟通"）→ 最终判断环境是否需要改变 | 盲区：用户没意识到自己一直用别人的标准衡量自己；限制性信念："快才好" |

**关键洞察**：如果没有六层次，教练可能会在下层打转——帮用户改简历、分析市场、找新工作。如果没有冰山模型，教练可能只看到"我不适合"这个身份认知，而看不到下面还有"快才好"的限制性信念和"需要被认可"的深层需求。

## 五、教练判断速查表

### 听用户语言，判断问题在哪个层次

| 用户说的话 | 层次 | 正确的教练方向 |
|-----------|------|---------------|
| "公司太远了"、"加班太多"、"同事不好"、"工资太低" | 环境层 | 先向上一层问："你说的这些问题，换个环境能解决吗？" |
| "我每天都很忙"、"我做了很多但没效果" | 行为层 | 先向上一层问："你做这些事的时候，觉得自己的能力够吗？" |
| "我不知道怎么做"、"我学不会"、"别人都比我快" | 能力层 | 先向上一层问："你为什么觉得自己学不会？是方法问题，还是你觉得自己'不是学这个的人'？" |
| "这不公平"、"努力没用"、"成功就是有钱" | 信念/价值观层 | 向下潜入：这个信念从哪里来？它保护过你什么？现在还在保护你吗？ |
| "我不是做这个的料"、"我就是这样的人"、"我不配" | 身份层 | 向下潜入：这个身份认知从哪里来？有什么证据？有没有例外？ |
| "我不知道自己为什么活着"、"感觉做什么都没意义" | 精神层 | 向下潜入：你上一次觉得"有意义"是什么时候？什么事？ |

### 听用户语言，判断需要哪个模型

| 用户信号 | 首选模型 | 为什么 |
|----------|----------|--------|
| "我试过了，没用" | 六层次 | 可能在下层解决上层问题 |
| "我不知道自己喜欢什么" | 冰山（从 L3 心流切入） | 需要从表层潜入深层 |
| "我觉得自己不行" | 六层次定位 + 冰山潜入 | 六层次判断是身份层问题，冰山潜入身份层以下的信念和恐惧 |
| "我想换工作/转行" | 六层次定位 | 先判断是环境问题还是上层问题 |
| "我好像总是这样" | 冰山潜入 | 需要看到重复模式背后的深层原因 |
| "别人都说我……但我自己不觉得" | 冰山（L8 盲区） | 需要探索盲区 |
| "我明明知道该改，但就是改不了" | 变革免疫 + 六层次 | 六层次定位卡在哪层，变革免疫探索限制性信念 |
