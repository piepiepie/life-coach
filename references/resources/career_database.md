# 职业方向数据库

> 本文档作为自我探索教练（Self-Discovery Coach）的职业方向参考库，涵盖12个传统职业类别和4个方向（其中 AI/数据 已于 1.4 复核调整为主流赛道），每个类别提供：描述、霍兰德代码匹配、适合的MBTI类型、核心优势需求及DISC风格适配。  
> **重要提示**：本数据库是起点参考，而非刚性处方。测评结果只能提供概率性建议，最终职业方向需结合个人兴趣、能力、价值观和市场现实综合判断。
>
> **1.3 时效说明（新增）**：职业世界变化快，本库所有方向均带"数据时效"属性。各方向最后校验日期与状态见文末 §二点五《职业数据时效登记表》。AI 在引用任一方向做关键决策前，**必须**按 `integration/market_data_protocol.md` 重新检索该方向的当下市场现实（薪资/趋势/门槛），**不得**直接用本库静态描述当作最新事实。过时方向应在登记表中标记并提示用户。

## 三、使用指南

### 3.1 匹配原则

| 原则 | 说明 |
|------|------|
| **多维度交叉** | 不依赖单一模型，综合霍兰德、MBTI、VIA、DISC等交叉验证 |
| **概率非确定** | 测评结果给出的是"更可能匹配"的方向，绝非"唯一正确的方向" |
| **兴趣优先** | 当测评结果与用户兴趣冲突时，优先尊重用户的主观兴趣和热情 |
| **动态调整** | 职业方向随人生阶段、市场环境和个人成长而变，本库是起点而非终点 |

### 3.2 推荐流程

```
用户测评结果 → 提取多维模型特征 → 匹配数据库中的职业类别 → 筛选2-3个候选方向
    → 结合用户兴趣和价值观进行二次筛选 → 推荐1-2个方向 + 探索行动建议
```

### 3.3 注意事项

1. **避免刻板印象**：测评模型是描述性工具，不是规范性工具。不要因为用户是"ISFJ"就断言其"不适合创业"。
2. **关注边缘案例**：任何MBTI类型在任何职业中都可能成功，许多杰出人士的职业选择在模型看来"不匹配"。
3. **强调探索**：职业方向不是"选"出来的，而是通过小步试错"探"出来的。推荐方向后应配合"最小可尝试行动"建议。
4. **警惕过度简化**：职业世界远比12个类别复杂，本数据库是分类框架而非穷举列表。
5. **持续更新**：新兴职业不断涌现，教练应定期更新本数据库，捕捉行业变化。具体时效追踪见 §二点五《职业数据时效登记表》——引用任一方向做关键决策前，须按 `integration/market_data_protocol.md` 重新检索其当下市场现实，不得直接以本库静态描述当作最新事实。

---

> **使用说明**：教练应在完成用户完整测评后，综合霍兰德、MBTI、VIA、DISC等多维度数据，从本数据库中筛选2-3个候选方向，结合用户自述的兴趣、价值观和现实约束，进行个性化推荐。推荐时应同时给出"为什么是这些方向"的测评依据和"如何验证这些方向"的行动建议。
