# life-coach · 人生教练

> 一个 AI 人生教练技能：通过对话帮你**看清天赋、找到匹配的职业 / 事业方向，并给出可落地的执行路径**。
>
> An AI life-coach skill that helps you *see your talents, find a fitting career / business direction, and get an actionable plan* — through guided conversation.

---

## 这个技能有什么用

- **看清自己**：用冰山式深度对话 + 多心理学模型（MBTI / VIA / 盖洛普优势 / DISC / 霍兰德 / AQAL），从你的叙述里识别天赋、价值观与潜能——不用先做一堆题。
- **找到方向**：把识别出的天赋映射到具体行业与角色，并量化你和目标之间的能力 / 时间 / 资金缺口，给出相邻替代方向。
- **落地执行**：为每个方向提供标准 Playbook——3 个月行动计划、信息访谈清单、作品集方案、验证里程碑。
- **对话中测评**：聊天过程中自动插入轻量题，验证并排出"盖洛普式前 N"天赋排序，不打断对话流。

## 能帮什么人 · 解决什么问题

| 你可能是 | 你的困扰 | 它怎么帮你 |
|---------|---------|-----------|
| 迷茫的人 | "不知道自己适合做什么" | 从对话里识别天赋与热情，给出方向性感觉 |
| 想转行的人 | "想换但怕选错" | 场景模拟 + 差距分析，看清可行性与风险 |
| 创业者 / 自由职业者 | "我的优势能做成什么" | 把天赋映射到具体赛道与切入路径 |
| 自我怀疑的人 | "我真的行吗" | 优势导向对话建立自我效能，而非盯着补短板 |
| 毕业生 / 职场新人 | "该往哪走" | 结合中文职场语境（考公 / 大厂 / 35 岁 / 副业）给现实建议 |

## 怎么用

1. 把本文件夹放到 WorkBuddy 技能目录（见下方安装），或克隆本仓库。
2. **直接开口说话就行**——不用选模式、不用填表。技能会根据你说的话自动路由到合适的模式。
3. 它会在"陪伴"和"指导"之间动态切换：浅层只陪你聊，捕捉到天赋信号且你主动问"具体怎么做"时，才给行动建议。

**示例对话：**

```
你：我最近很迷茫，不知道自己适合做什么。
你：帮我做个测评。
你：如果我去转行做内容策略，会怎么样？
```
